人工知能の定義

0/25
到達目標
  • 人工知能とは何か、具体例を用いて説明できる
  • 人工知能のレベルを4つに分類し説明できる
  • AI効果を説明できる
  • 人工知能とロボットの違いを説明できる
人工知能公式AI / Artificial Intelligence
「知的な機械、特に知的なコンピュータプログラムを作る科学と技術」(マッカーシー)。専門家の間でも統一した定義は存在せず、研究者ごとに定義が異なる。
AI効果公式AI Effect
AIの原理・仕組みが分かってしまうと「それは単なる自動化であって知能ではない」と結論づけてしまう人間の心理的傾向。AIの成果が過小評価される原因。
エージェント公式Agent
環境を知覚(センサ)し、自律的に判断して環境に働きかける(アクチュエータ)主体。AIをエージェントとして捉える見方。強化学習では学習の主体を指す。
機械学習公式Machine Learning
コンピュータがデータからパターンやルールを自動的に学習し、未知データに対して予測・判断を行う技術。人工知能の一分野。
ディープラーニング公式深層学習 / Deep Learning
多層のニューラルネットワークを用いる機械学習手法。特徴量そのものをデータから獲得(特徴表現学習)できる点が従来手法との決定的な違い。
AIのレベル1単純な制御プログラム
あらかじめ決められた振る舞いのみを行う。制御工学の範疇で、厳密にはAIとは言い難い。エアコン、洗濯機、単純な温度制御など。
AIのレベル2古典的な人工知能
探索・推論・知識ベースを用い、入力と出力の組み合わせが極めて多彩なもの。掃除ロボット、診断プログラム、パズルを解くプログラムなど。
AIのレベル3機械学習を取り入れたAI
サンプルデータをもとにルールや知識を自ら学習するもの。検索エンジン、ビッグデータ分析など。特徴量は人間が設計する。
AIのレベル4ディープラーニングを取り入れたAI
特徴量そのものを学習(特徴表現学習)するもの。画像認識・音声認識・自動翻訳など。
人工知能とロボットの違い
ロボット研究は身体を持つ機械全般が対象。人工知能研究はロボットの「頭脳」にあたる部分を扱い、必ずしも身体を必要としない。
特化型人工知能Narrow AI / 狭い人工知能
特定の決まったタスクのみをこなすAI。現在実用化されているAIのほぼすべて。※「特化型/汎用」はこなせるタスクの範囲による区分、「強いAI/弱いAI」は心を持ちうるかという哲学的な区分であり、別の軸なので混同しないこと。
汎用人工知能AGI / Artificial General Intelligence
人間と同様に、異なる分野の多様な問題を自ら考えて解決できるAI。未実現。
ダートマス会議公式Dartmouth Conference
1956年開催。ジョン・マッカーシーが「人工知能(Artificial Intelligence)」という言葉を初めて用いた。AI研究の出発点とされる。
ジョン・マッカーシーJohn McCarthy
「人工知能」の名付け親。ダートマス会議の主催者。LISPの開発者。フレーム問題の共同提唱者。
マービン・ミンスキーMarvin Minsky
ダートマス会議参加者。フレーム理論の提唱者。著書『パーセプトロン』で単純パーセプトロンの限界を指摘。
アレン・ニューウェルAllen Newell
ハーバート・サイモンと共に世界初のAIプログラム「ロジック・セオリスト」を開発。
ハーバート・サイモンHerbert Simon
ロジック・セオリストの共同開発者。限定合理性の研究でノーベル経済学賞を受賞。
ロジック・セオリストLogic Theorist
1956年、ニューウェルとサイモンによる世界初の人工知能プログラム。数学の定理を自動証明した。※シラバス2024でキーワードからは削除。
アラン・チューリングAlan Turing
計算機科学の父。チューリングマシン、チューリングテストの提唱者。論文「計算する機械と知性」(1950)。
第1次AIブーム推論・探索の時代
1950年代後半〜1960年代。探索と推論により迷路やパズルは解けたが、現実の複雑な問題は解けず(トイ・プロブレム批判)、冬の時代へ。
第2次AIブーム知識の時代
1980年代。エキスパートシステムが実用化された。知識獲得のボトルネックにより再び冬の時代へ。日本の第五世代コンピュータもこの時期。
第3次AIブーム機械学習・特徴表現学習の時代
2010年代〜。ビッグデータと計算資源の増大により機械学習・ディープラーニングが実用化。生成AIへと発展。
AIの冬AI Winter
期待が失われ研究資金と関心が縮小した時期。1970年代と、1980年代後半〜1990年代前半の2回。
第五世代コンピュータ
1982〜1992年の日本の国家プロジェクト。推論に特化した並列コンピュータの開発を目指したが、期待した成果は得られなかった。
JDLA日本ディープラーニング協会
G検定・E資格を実施する一般社団法人。理事長は松尾豊。ディープラーニングの産業活用促進が目的。

人工知能分野で議論される問題

0/28
到達目標
  • 人工知能分野で議論されている代表的な問題について説明できる
  • 汎用的な人工知能の実現可能性について、いくつかの例を取り上げて説明できる
シンギュラリティ公式技術的特異点 / Technological Singularity
AIが自分自身よりも賢いAIを作れるようになる時点。以後、知能爆発により人類には予測不能な進化が起きるとされる。
シンボルグラウンディング問題公式Symbol Grounding Problem
1990年スティーブン・ハルナッドが提唱。記号(シンボル)とそれが指し示す意味・対象を結びつけられないという問題。「シマウマ」という記号と実際の縞馬を結びつけられない。
身体性公式Embodiment
身体を通して外界と相互作用することが、概念の理解や知能の獲得に不可欠だとする考え方。シンボルグラウンディング問題への一つの答え。
トイ・プロブレム公式Toy Problem
迷路やパズルなど、ルールが明確に定められた簡単な問題。第1次AIブームのAIはこれしか解けないと批判された。
知識獲得のボトルネック公式Knowledge Acquisition Bottleneck
専門家の知識をコンピュータが扱える形で大量に記述することが極めて困難であるという問題。第2次AIブーム終焉の主因。
チューリングテスト公式Turing Test
別の場所にいる人間が対話相手を機械だと見抜けなければ、その機械には知能があるとする判定法。イミテーションゲームとも呼ばれる。
中国語の部屋公式Chinese Room
ジョン・サールの思考実験。中国語を理解しない人がマニュアル通りに記号を操作しても、外からは理解しているように見える。強いAIへの反論。
強いAIと弱いAI公式Strong AI / Weak AI
ジョン・サールの分類。強いAI=適切にプログラムされた計算機は心を持ちうるとする立場。弱いAI=心を持つ必要はなく、有用な道具として知的作業を模倣すればよいとする立場。
フレーム問題公式Frame Problem
1969年ジョン・マッカーシーとパトリック・ヘイズが提唱。今しようとしていることに関係のある事柄だけを選び出すことが、有限の処理能力しかないAIには困難であるという問題。
統計的機械翻訳公式SMT / Statistical Machine Translation
大量の対訳コーパスから統計的に訳語・語順を学習して翻訳する方式。ルールベース翻訳の後、ニューラル機械翻訳の前に主流だった。
ルールベース機械翻訳公式RBMT / Rule-Based Machine Translation
文法規則と対訳辞書を人手で記述して翻訳する方式。例外や曖昧性への対応が難しい。
ローブナーコンテスト公式Loebner Prize
1991年から2019年まで開催された、チューリングテストに合格するAIを目指すコンテスト。2020年以降は事実上終了している。
ジョン・サールJohn Searle
哲学者。「強いAI・弱いAI」の分類と「中国語の部屋」の提唱者。
スティーブン・ハルナッドStevan Harnad
シンボルグラウンディング問題の提唱者。
ダニエル・デネットDaniel Dennett
フレーム問題を「爆弾と台車のロボット」の思考実験でわかりやすく説明した哲学者。
ロジャー・ペンローズRoger Penrose
著書『皇帝の新しい心』で、意識は量子効果によるもので計算機には実現できないとして強いAIを否定した。
ELIZA(イライザ)ELIZA
1966年ジョセフ・ワイゼンバウムが開発した対話システム。精神科セラピストを模し、パターンマッチで応答を返す。
イライザ効果ELIZA Effect
機械の反応を、無意識のうちに人間的なものと解釈してしまう心理的傾向。
レイ・カーツワイルRay Kurzweil
2045年にシンギュラリティが到来すると予測。「収穫加速の法則」を提唱。
ヴァーナー・ヴィンジVernor Vinge
「シンギュラリティ」の概念を広めたSF作家・数学者。「人間の手によって、人間を超える知能が作られる時点」と定義。
2045年問題
カーツワイルが予測したシンギュラリティ到来年。2029年にAIが人間並みの知能を持つとも予測している。
収穫加速の法則Law of Accelerating Returns
技術進歩は直線的ではなく指数関数的に加速するという法則。
ムーアの法則Moore's Law
半導体の集積率は約18〜24か月で2倍になるという経験則。
オレン・エツィオーニOren Etzioni
シンギュラリティに懐疑的な立場の研究者。AIが人類を滅ぼすという懸念を否定。
スティーブン・ホーキングStephen Hawking
「完全な人工知能の開発は人類の終焉を意味するかもしれない」と警告した物理学者。
イーロン・マスクElon Musk
AIの脅威に警鐘を鳴らす実業家。OpenAIの共同設立に関与した。Future of Life Institute(2014年にテグマークらが設立)には設立者ではなく大口の資金提供者として関わった。
特徴量設計Feature Engineering
対象の特徴を数値化した変数(特徴量)を人間が設計する作業。従来の機械学習では職人技を要した。
特徴表現学習Representation Learning
特徴量そのものをデータから自動的に学習する手法。ディープラーニングの本質的功績。

探索木公式Search Tree
場合分けを木構造で表現し、根から順にたどって解を探す手法。
幅優先探索公式BFS / Breadth First Search
同じ階層のノードをすべて調べてから次の階層へ進む。辺のコストが一様なら最短経路が必ず見つかるが、途中の全ノードを記憶するためメモリ消費が大きい。
深さ優先探索公式DFS / Depth First Search
一つの枝を行き止まりまでたどってから戻る(バックトラック)。メモリ消費は少ないが、最短経路の保証はなく運次第で時間がかかる。
ハノイの塔公式Tower of Hanoi
探索木で解ける代表的なトイ・プロブレム。3本の杭と大きさの異なる円盤のパズル。
ブルートフォース公式力任せ探索 / Brute Force
可能な組み合わせをすべて調べ尽くす手法。組み合わせ爆発により現実問題では破綻しやすい。
Mini-Max法公式ミニマックス法
自分の手番ではスコアが最大に、相手の手番では最小になる手が選ばれると仮定して先読みするゲーム探索法。
αβ法公式Alpha-Beta Pruning
Mini-Max法の枝刈り手法。調べる必要のない枝を打ち切る。最小値を選ぶ過程で不要な枝を切るのがαカット、最大値を選ぶ過程で切るのがβカット。
モンテカルロ法公式Monte Carlo Method
乱数を用いたシミュレーションを多数試行して近似解を得る手法。ゲームでは終局までランダムに打つ(プレイアウト)。
STRIPS公式Stanford Research Institute Problem Solver
1971年リチャード・ファイクスとニルス・ニルソンが開発したプランニング手法。「前提条件」「行動」「結果」の3要素で世界を記述する。
SHRDLU公式SHRDLU
1970年前後にテリー・ウィノグラードが開発。「積み木の世界」を英語の対話で操作できるシステム。後のCycプロジェクトにつながった。
プランニングPlanning
ロボットの行動計画。目標状態に至る行動系列を探索により求める技術。
反復深化深さ優先探索Iterative Deepening DFS
深さ制限を段階的に増やしながら深さ優先探索を繰り返す。最短性と省メモリ性を両立する。
組み合わせ爆発Combinatorial Explosion
場合の数が指数関数的に増大し、現実的な時間で全探索できなくなる現象。
ヒューリスティックHeuristic
経験則。探索を効率化するための、最適性は保証しないが有用な指針。
コストCost
探索において目標に到達するまでにかかる手数や距離。コストの低い方を優先すると効率化できる。
A*アルゴリズムA-star
実コストと推定コスト(ヒューリスティック)の和が最小の経路を優先探索する手法。
プレイアウトPlayout
ゲームで終局まで完全にランダムに打ち続けること。原始モンテカルロ法の基礎。
原始モンテカルロ法Primitive Monte Carlo
評価関数を用いず、プレイアウトの勝率のみで手を評価する手法。
モンテカルロ木探索MCTS / Monte Carlo Tree Search
有望な手を優先して深く探索するモンテカルロ法の発展形。AlphaGoでも採用された。
局面評価関数Evaluation Function
ゲームの盤面の有利・不利を数値化する関数。かつては人間が設計していたが、Bonanzaが機械学習で自動獲得した。
Deep Blueディープ・ブルー
1997年、IBMのチェス専用機。世界チャンピオンのガルリ・カスパロフに勝利した。
Bonanzaボナンザ
局面評価関数を機械学習で自動獲得した将棋プログラム(Bonanzaメソッド)。
Ponanzaポナンザ
2017年、佐藤天彦名人に勝利した将棋AI。

知識表現とエキスパートシステム

0/30
到達目標
  • 知識表現とは何か説明できる
  • エキスパートシステムとは何か説明できる
  • 知識表現・エキスパートシステムに係る代表的な研究や手法を理解する
Cycプロジェクト公式Cyc Project
1984年ダグラス・レナートが開始。すべての一般常識をコンピュータに入力しようとする、現在も続くプロジェクト。ヘビーウェイトオントロジーの代表例。
DENDRAL公式デンドラル
1960年代にエドワード・ファイゲンバウムが開発した世界初のエキスパートシステム。未知の有機化合物を質量分析データから特定する。
is-a の関係公式継承関係
「AはBの一種である」という上位・下位概念の関係。推移律が成り立つ(A is-a B, B is-a C ⇒ A is-a C)。
has-a の関係公式
「AはBを部分として持つ」という関係。part-ofの逆向きの関係。
part-of の関係公式属性・部分関係
「AはBの一部である」という全体と部分の関係。5種類以上に細分され、推移律が常に成り立つとは限らない。
Question-Answering公式質問応答システム
自然言語で与えられた質問に対して適切な回答を返すシステム。ワトソンが代表例。
意味ネットワーク公式Semantic Network
概念をノード、概念間の関係をリンク(矢印)で表現した知識表現。もとは認知心理学の考え方。
イライザ (ELIZA)公式ELIZA
1966年ジョセフ・ワイゼンバウムが開発した、パターンマッチにより人間らしい応答を返す対話システム。
インタビューシステム公式Interview System
エキスパートシステムにおいて、専門家から知識を効率的に引き出すためのシステム。知識獲得のボトルネックへの対策。
ウェブマイニング公式Web Mining
ウェブ上のデータやアクセスログから有用な知識を抽出する技術。ライトウェイトオントロジー構築に利用される。
オントロジー公式Ontology
知識を体系的に記述するための「概念化の明示的な仕様」(トム・グルーバー)。もとは哲学用語で「存在論」。
セマンティックWeb公式Semantic Web
ウェブ上の情報に意味(メタデータ)を付与し、機械が理解・処理できるようにする構想。ティム・バーナーズ=リーが提唱。
データマイニング公式Data Mining
大量のデータから統計的手法などで有用なパターンや知識を掘り起こす技術。
東ロボくん公式
2011年から国立情報学研究所(新井紀子)が進めた、東大合格を目指すAIプロジェクト。読解力の壁により2016年に東大受験を断念。
マイシン (MYCIN)公式MYCIN
1970年代スタンフォード大学で開発。血液中のバクテリアを診断し抗生物質を処方する医療エキスパートシステム。約500のルールを持ち、専門医には及ばないが非専門医より高い正解率を示した。
ワトソン公式Watson

教師あり学習

0/38
到達目標
  • 教師あり学習には特徴量と教師データのペアが必要であることを理解する
  • 分析対象に応じた問題の種類を列挙・説明できる
  • 代表的な教師あり学習モデルの基本概念を理解する
  • 目的やデータの特性・量に応じて適切なモデルを選択できる
教師あり学習Supervised Learning
入力(特徴量)と正解(教師データ)のペアを与えて、その対応関係を学習させる方式。分類問題と回帰問題に大別される。
分類問題公式Classification
出力が離散的なカテゴリである問題。スパム判定、画像のクラス分けなど。
回帰問題公式Regression
出力が連続値である問題。売上予測、株価予測、気温予測など。
多クラス分類公式Multi-class Classification
3つ以上のクラスに分類する問題。出力層にソフトマックス関数を用いるのが一般的。※各サンプルが複数ラベルを持つ場合は多ラベル分類。
二値分類Binary Classification
2クラスに分類する問題。出力層にシグモイド関数を用いる。
線形回帰公式Linear Regression
データを直線(超平面)で近似し、連続値を予測する最も基本的な手法。最小二乗法でパラメータを求める。
重回帰分析公式Multiple Regression Analysis
説明変数が2つ以上の線形回帰。説明変数間に強い相関があると多重共線性(マルチコ)の問題が生じる。
多重共線性Multicollinearity
重回帰分析で説明変数どうしの相関が強いとき、回帰係数が不安定になる現象。VIFで検出する。
最小二乗法Least Squares Method
予測値と実測値の残差の二乗和を最小にするようにパラメータを決定する方法。
ロジスティック回帰公式Logistic Regression
名称は回帰だが分類に用いる手法。シグモイド関数で出力を0〜1の確率に変換する。多クラスではソフトマックス関数を用いる。
シグモイド関数Sigmoid Function
任意の実数を0〜1に写像するS字型の関数。二値分類の出力や、かつては活性化関数として用いられた。
尤度・最尤推定Likelihood / MLE
観測データが得られる確率(尤度)を最大にするようにパラメータを推定する方法。ロジスティック回帰の学習に用いる。
決定木公式Decision Tree
データを条件分岐で順に分割して予測する木構造モデル。解釈性が高く、スケーリング(正規化)が不要。不純度(ジニ係数・エントロピー)や情報利得を基準に分割する。
ジニ係数Gini Impurity
決定木の分割基準に用いる不純度指標。値が小さいほどクラスが純粋。
情報利得Information Gain
分割前後のエントロピーの減少量。決定木でこれが最大になる分割を選ぶ。
CART / ID3 / C4.5
代表的な決定木アルゴリズム。CARTは二分木で分類・回帰の両方に対応、ID3・C4.5は多分岐でエントロピー基準を用いる。
ランダムフォレスト公式Random Forest
複数の決定木を作り多数決(平均)を取るバギング系アンサンブル手法。各木でデータと特徴量の両方をランダムに選ぶ点が特徴。過学習しにくく、特徴量重要度が得られる。
アンサンブル学習公式Ensemble Learning
複数の弱学習器を組み合わせて高い性能を得る手法の総称。バギング、ブースティング、スタッキングなど。
バギング公式Bagging / Bootstrap Aggregating
ブートストラップサンプリングで作った複数のデータセットで並列に学習し、結果を平均・多数決する。バリアンスを下げ過学習を抑える。
ブースティング公式Boosting
弱学習器を逐次的に学習させ、前の学習器が誤ったデータを重点的に学習する。バイアスを下げ精度は高いが、逐次処理のため並列化しにくく過学習しやすい。
ブートストラップサンプリング公式Bootstrap Sampling
元データから重複を許してランダムに標本を復元抽出すること。バギングの基礎。
AdaBoost公式アダブースト
代表的なブースティング手法。誤分類したサンプルの重みを大きくして次の弱学習器を学習させる。
勾配ブースティング公式Gradient Boosting
前の学習器の残差(誤差の勾配)を次の学習器が予測するように逐次学習するブースティング手法。
XGBoost / LightGBM / CatBoost
勾配ブースティングの高速・高精度な実装。表形式データのコンペで広く使われる。
スタッキングStacking
複数モデルの予測結果をさらに別のモデル(メタモデル)の入力として学習させるアンサンブル手法。
サポートベクターマシン (SVM)公式Support Vector Machine
マージン最大化により2クラスを分ける超平面を求める手法。ディープラーニング以前の代表的高性能手法。
マージン最大化公式Margin Maximization
分離超平面と最も近いデータ点(サポートベクター)との距離を最大にすること。汎化性能を高める。
サポートベクターSupport Vector
分離超平面に最も近いデータ点。これのみが超平面の決定に寄与する。
スラック変数 / ソフトマージンSlack Variable / Soft Margin
誤分類をある程度許容することで、線形分離できないデータにもSVMを適用できるようにする仕組み。
カーネル公式Kernel
データを高次元空間へ写像する関数。線形分離できないデータを高次元で分離可能にする。
カーネルトリック公式Kernel Trick
高次元への写像を実際に計算せず、内積をカーネル関数で置き換えることで計算量を抑える技法。
RBFカーネル動径基底関数カーネル / ガウシアンカーネル
最もよく使われるカーネル関数。無限次元への写像に相当する。
自己回帰モデル (AR)公式Autoregressive Model
時系列データにおいて、過去の自分自身の値の線形結合で現在値を予測するモデル。
ベクトル自己回帰モデル (VARモデル)公式Vector Autoregression
ARモデルを多変量に拡張したもの。複数の時系列が互いに影響し合う関係を扱える。
ARMA / ARIMA
ARに移動平均(MA)を組み合わせたモデル(ARMA)、さらに差分により非定常データに対応したモデル(ARIMA)。
k近傍法 (k-NN)k-Nearest Neighbor
予測したい点の近傍k個の多数決(平均)で予測する。学習フェーズを持たない怠惰学習の代表。
ナイーブベイズNaive Bayes
ベイズの定理を用い、特徴量どうしが条件付き独立と仮定して分類する手法。テキスト分類・スパムフィルタで有効。
単純パーセプトロンSimple Perceptron
入力層と出力層のみからなる最も単純なニューラルネットワーク。線形分離可能な問題しか解けない。

教師なし学習

0/23
到達目標
  • 教師なし学習には特徴量のみが必要であることを理解する
  • 分析対象に応じた問題の種類を列挙・説明できる
  • 代表的な教師なし学習モデルの基本概念を理解する
教師なし学習Unsupervised Learning
正解ラベルを与えず、データそのものの構造・パターンを見つける方式。クラスタリング、次元削減などが該当する。
クラスタリング公式Clustering
データを類似性に基づいて自動的にグループ(クラスタ)分けする手法。非階層的手法と階層的手法がある。
k-means法公式k平均法
あらかじめクラスタ数kを指定し、各点を最も近い重心に割り当てる→重心を再計算、を収束まで繰り返す非階層クラスタリング。初期値依存があり、k-means++で改善される。
ウォード法公式Ward's Method
階層クラスタリングの一種。クラスタ内の分散(平方和)の増加が最小になるように併合していく。
デンドログラム (樹形図)公式Dendrogram
階層クラスタリングの結果を木構造で表した図。切る高さでクラスタ数を決められる。
階層クラスタリングHierarchical Clustering
データを1つずつ併合(凝集型)または分割していく手法。クラスタ数を事前に決めなくてよい。最短距離法・最長距離法・群平均法・ウォード法など。
次元削減公式Dimensionality Reduction
情報をなるべく失わずに特徴量の数を減らすこと。可視化、計算量削減、次元の呪いの回避が目的。
主成分分析 (PCA)公式Principal Component Analysis
データの分散が最大になる方向(主成分)を順に求めて次元を圧縮する線形の次元削減手法。寄与率・累積寄与率で情報の保持量を評価する。
寄与率・累積寄与率Contribution Ratio
各主成分が元データの分散をどれだけ説明するかの割合、およびその累積。
特異値分解 (SVD)公式Singular Value Decomposition
任意の行列を3つの行列の積に分解する線形代数の手法。PCAや潜在意味解析(LSI)の基礎、推薦システムにも利用。
多次元尺度構成法公式MDS / Multi-Dimensional Scaling
データ間の距離(非類似度)関係をできるだけ保ったまま低次元空間に配置する可視化手法。
t-SNE公式t-distributed Stochastic Neighbor Embedding
高次元データを2〜3次元へ可視化する非線形次元削減手法。近い点どうしの局所構造の保持に優れる。t分布を用いる。
UMAPUniform Manifold Approximation and Projection
t-SNEより高速で大域構造も保ちやすい非線形次元削減・可視化手法。
独立成分分析 (ICA)Independent Component Analysis
信号を統計的に独立な成分に分解する手法。カクテルパーティー効果の再現(音源分離)などに用いる。
協調フィルタリング公式Collaborative Filtering
「あなたと似た嗜好の人が好んだもの」を推薦する方式。ユーザ間の評価行列を利用する。事前にアイテムの中身の情報は不要。
コールドスタート問題公式Cold Start Problem
協調フィルタリングで、新規ユーザ・新規アイテムに関する評価データがないため推薦できない問題。
コンテンツベースフィルタリング公式Content-Based Filtering
アイテム自体の特徴(属性)とユーザの嗜好を照合して推薦する方式。コールドスタート問題に強いが、意外性のある推薦は生まれにくい。
トピックモデル公式Topic Model
文書が複数の潜在的なトピックの混合から生成されると仮定するモデル。文書を1つのクラスタに限定しない点がクラスタリングと異なる。
潜在的ディリクレ配分法 (LDA)公式Latent Dirichlet Allocation
代表的なトピックモデル。各文書のトピック分布と各トピックの単語分布をディリクレ分布を事前分布として推定する。※線形判別分析(LDA)とは別物なので注意。
潜在意味解析 (LSI/LSA)Latent Semantic Indexing
単語-文書行列を特異値分解し、潜在的な意味の次元を抽出する手法。
アソシエーション分析Association Analysis
「AとBが同時に買われる」といった相関ルールを発見する手法。支持度・確信度・リフト値で評価。アプリオリアルゴリズムが有名。
異常検知Anomaly Detection
正常データの分布から外れたデータを検出する手法。教師なし学習で扱われることが多い。
自己組織化マップ (SOM)Self-Organizing Map
コホネンが考案した、高次元データを2次元格子に写像して可視化するニューラルネットワーク。

強化学習

0/22
到達目標
  • 強化学習の基本概念を理解する
  • 教師あり学習・教師なし学習との差異を説明できる
  • 価値関数の学習と方策の学習の2つの代表的アプローチを理解する
強化学習Reinforcement Learning
エージェントが環境と試行錯誤しながら相互作用し、累積報酬を最大化する行動方策を学習する枠組み。正解データではなく報酬という間接的な信号で学習する。
マルコフ決定過程公式MDP / Markov Decision Process
強化学習の数学的定式化。状態・行動・状態遷移確率・報酬で構成される。次状態が現在の状態と行動のみで決まる(マルコフ性)ことを仮定する。
割引率公式Discount Factor / γ
将来の報酬をどれだけ現在価値として重視するかを表す0〜1のパラメータ。1に近いほど長期的な報酬を重視する。
状態価値関数公式State Value Function / V(s)
ある状態から方策に従い行動した場合に得られる期待累積報酬。
行動価値関数公式Action Value Function / Q(s,a)
ある状態で特定の行動をとり、その後方策に従った場合に得られる期待累積報酬。Q値。
方策Policy / π
各状態でどの行動をとるかを決める規則。確率分布として表されることが多い。
ベルマン方程式Bellman Equation
価値関数が満たす再帰的な関係式。現在の価値=即時報酬+割引された次状態の価値。
Q学習公式Q-learning
行動価値関数Qを更新して最適方策を求める代表的な価値ベース手法。方策オフ型(off-policy)で、実際の行動とは別に最大のQ値を用いて更新する。
SARSAState-Action-Reward-State-Action
Q学習と似た価値ベース手法だが、実際に選んだ次の行動のQ値で更新する方策オン型(on-policy)。
方策オフ型・方策オン型Off-policy / On-policy
更新に用いる方策と実際に行動する方策が異なるのが方策オフ型(Q学習)、同一なのが方策オン型(SARSA)。
方策勾配法公式Policy Gradient Method
価値関数を経由せず、方策を直接パラメータ化して勾配法で最適化する手法。連続値制御に強い。
REINFORCE公式
代表的な方策勾配法。エピソード終了後の実際の収益を用いて方策を更新するモンテカルロ型の手法。AlphaGoでも利用。
Actor-Critic公式アクター・クリティック
行動を決める Actor(方策) と価値を評価する Critic(価値関数) を組み合わせた手法。方策ベースと価値ベースの利点を併せ持つ。
バンディットアルゴリズム公式Bandit Algorithm
多腕バンディット問題(どのスロットを引くか)を解く手法群。探索(exploration)と活用(exploitation)のトレードオフを扱う。
ε-greedy方策公式イプシロン・グリーディ方策
確率εでランダムに行動(探索)し、確率1−εで最も価値が高い行動を選ぶ(活用)方策。
UCB方策公式Upper Confidence Bound
期待値の推定値に「試行回数が少ないほど大きくなる不確実性の項」を加えて行動を選ぶ方策。理論的な後悔(regret)の上界が保証される。
探索と活用のトレードオフExploration-Exploitation Trade-off
未知の行動を試すか(探索)、現時点で最良の行動を取るか(活用)のジレンマ。
ボルツマン選択Boltzmann Selection / softmax方策
Q値に応じた確率で行動を選ぶ方策。温度パラメータで探索の度合いを調整する。
TD学習Temporal Difference Learning
1ステップ先の推定値を用いて価値関数を逐次更新する手法。モンテカルロ法と動的計画法の中間的手法。
モンテカルロ法(強化学習)Monte Carlo Method
エピソードを最後まで実行し、実際に得られた収益で価値を更新する手法。
報酬成形Reward Shaping
学習を促進するために報酬関数を工夫して設計すること。設計を誤ると意図しない行動を学習する。
多腕バンディット問題Multi-armed Bandit Problem
当たり確率の異なる複数のスロットマシンから、報酬を最大化するよう選択する問題。

モデルの選択・評価

0/35
到達目標
  • 基本的なモデルの選択基準、評価方法並びに評価指標を理解する
  • 訓練誤差と汎化誤差の違いを説明できる
  • 汎化性能の悪化につながる代表的な現象を列挙・説明できる
  • モデルの複雑さを上げるメリット・デメリットを理解する
汎化性能公式Generalization Performance
学習に使っていない未知のデータに対する予測性能。機械学習の最終目標。
過学習公式Overfitting / 過剰適合
訓練データに適合しすぎて、未知データへの性能が落ちる現象。モデルが複雑すぎる、データが少ない場合に起きやすい。
未学習Underfitting / 学習不足
モデルが単純すぎて訓練データにすら適合できていない状態。
バイアス・バリアンストレードオフBias-Variance Tradeoff
モデルを複雑にするとバイアス(偏り)は減るがバリアンス(ばらつき)が増え過学習しやすい、という関係。汎化誤差=バイアス²+バリアンス+ノイズ。
ホールドアウト検証公式Holdout Validation
データを訓練用とテスト用に一度だけ分割して評価する方法。単純だが分割の仕方に結果が左右される。
交差検証公式Cross Validation
データを複数の分割で繰り返し訓練・検証し、その平均で評価する方法。データが少ないときに有効。
k-分割交差検証公式k-fold Cross Validation
データをk個に分割し、1つを検証用・残りを訓練用として、これをk回繰り返して平均をとる方法。
Leave-One-Out交差検証LOOCV
1サンプルだけを検証用にする交差検証(k=データ数)。データが極端に少ないときに用いる。
層化抽出Stratified Sampling
分割時に各クラスの比率を元データと同じに保つ抽出法。不均衡データの評価で重要。
混同行列公式Confusion Matrix
分類結果を真陽性(TP)・偽陽性(FP)・偽陰性(FN)・真陰性(TN)の4象限で整理した表。各種評価指標の基礎。
偽陽性・偽陰性公式False Positive / False Negative
偽陽性(FP)=陰性を誤って陽性と判定(第一種の過誤)。偽陰性(FN)=陽性を誤って陰性と判定(第二種の過誤)。
正解率公式Accuracy
(TP+TN)/全体。全体のうち正しく判定できた割合。不均衡データでは実力を過大評価するので注意。
適合率公式Precision / 適合率
TP/(TP+FP)。陽性と予測したもののうち実際に陽性だった割合。誤検知を減らしたいときに重視。※日本語で単に「精度」というと正解率(Accuracy)を指すことが多いので注意。
再現率公式Recall / 感度
TP/(TP+FN)。実際に陽性のもののうち陽性と予測できた割合。見逃しを減らしたいとき(病気の診断など)に重視。
F値公式F-measure / F1スコア
適合率と再現率の調和平均。両者はトレードオフの関係にあり、そのバランスを1つの数値で表す。
特異度Specificity
TN/(TN+FP)。実際に陰性のもののうち陰性と判定できた割合。
マクロ平均・マイクロ平均Macro / Micro Average
多クラス分類で指標を統合する方法。マクロ平均はクラスごとの指標の単純平均、マイクロ平均は全サンプルをまとめて計算する。
ROC曲線公式Receiver Operating Characteristic Curve
判定のしきい値を変化させたときの偽陽性率(横軸)と真陽性率(縦軸)の関係を描いた曲線。
AUC公式Area Under the Curve
ROC曲線の下側の面積。0.5でランダム、1.0で完全な分類器。しきい値に依存しない総合的な評価指標。
PR曲線Precision-Recall Curve
適合率と再現率の関係を描いた曲線。不均衡データではROCよりも実態を反映しやすい。
MSE公式平均二乗誤差 / Mean Squared Error
誤差の二乗の平均。大きな誤差を強く罰する。回帰の代表的評価指標。
RMSE公式二乗平均平方根誤差 / Root Mean Squared Error
MSEの平方根。元のデータと同じ単位で解釈できる。
MAE公式平均絶対誤差 / Mean Absolute Error
誤差の絶対値の平均。外れ値の影響をMSEより受けにくい。
決定係数 R²Coefficient of Determination
回帰モデルがデータの分散をどれだけ説明できるかを表す指標。1に近いほど当てはまりが良い。
赤池情報量規準 (AIC)公式Akaike Information Criterion
モデルの当てはまりの良さとパラメータ数(複雑さ)のバランスでモデルを選ぶ指標。値が小さいほど良い。
ベイズ情報量規準 (BIC)公式Bayesian Information Criterion
AICと同様のモデル選択規準だが、標本数に応じてパラメータ数へのペナルティがより強い。
オッカムの剃刀公式Occam's Razor
「必要以上に多くの仮定をすべきでない」という指針。同程度の説明力なら単純なモデルを選ぶべきという考え方。
ノーフリーランチ定理No Free Lunch Theorem
あらゆる問題に対して万能に優れたアルゴリズムは存在しないという定理。
醜いアヒルの子の定理Ugly Duckling Theorem
何らかの前提(観点)がなければ、あらゆる対象は互いに同程度に似ているという定理。特徴量選択の必要性を示す。
データリーケージData Leakage
本来使えないはずの情報(正解に関わる情報や未来の情報)が学習に混入し、検証時に不当に高い精度が出る現象。
不均衡データImbalanced Data
クラス間のサンプル数が大きく偏ったデータ。アンダーサンプリング、オーバーサンプリング、SMOTE等で対処する。
ハイパーパラメータHyperparameter
学習で自動獲得されず、人が事前に設定する値(学習率、層数、木の深さ、kなど)。
グリッドサーチ・ランダムサーチGrid Search / Random Search
ハイパーパラメータの候補を総当たりで試す方法/ランダムに試す方法。
ベイズ最適化Bayesian Optimization
過去の試行結果から次に試すべきハイパーパラメータを効率的に選ぶ最適化手法。
疑似相関Spurious Correlation
直接の因果関係がないのに、共通の第三の要因(交絡因子)によって相関があるように見える現象。

ニューラルネットワークとディープラーニング

0/17
到達目標
  • ニューラルネットワークの基礎的な知識を理解する
  • ニューラルネットワークとディープラーニングの関係を説明できる
  • 学習に必要なデータ量や計算リソースについて理解する
  • CPU・GPU・TPUの特徴をそれぞれ説明できる
単純パーセプトロン公式Simple Perceptron
1958年ローゼンブラットが考案。入力層と出力層のみの最も単純なニューラルネットワーク。線形分離可能な問題しか解けず、XOR問題を解けないことをミンスキーらが指摘した。
多層パーセプトロン公式MLP / Multilayer Perceptron
入力層と出力層の間に隠れ層(中間層)を持つニューラルネットワーク。非線形分離が可能になり、XOR問題も解ける。
入力層公式Input Layer
データを受け取る最初の層。ノード数は特徴量の数に一致する。
隠れ層公式Hidden Layer / 中間層
入力層と出力層の間の層。層を深く(多層に)したものがディープラーニング。
出力層公式Output Layer
最終的な予測を出力する層。回帰なら恒等関数、二値分類ならシグモイド、多クラス分類ならソフトマックスを用いる。
CPU公式Central Processing Unit
汎用的な逐次処理に優れる演算装置。コア数は少ないが、複雑で多様な処理を高速にこなす。
GPU公式Graphics Processing Unit
もとは画像処理用。多数のコアによる大規模な並列演算(行列積)が得意で、ディープラーニングの学習・推論に適する。汎用計算に用いることをGPGPUという。
TPU公式Tensor Processing Unit
Googleが開発したディープラーニング専用プロセッサ。テンソル演算に特化し、GPUよりさらに高速・低消費電力。
GPGPUGeneral-Purpose computing on GPU
GPUを画像処理以外の汎用計算に利用すること。NVIDIAのCUDAが代表的な開発環境。
ニューロン(人工ニューロン)Artificial Neuron
入力に重みを掛けて総和をとり、バイアスを加えて活性化関数を通す計算単位。
重み・バイアスWeight / Bias
ニューラルネットワークが学習によって獲得するパラメータ。重みは入力の重要度、バイアスは発火のしやすさを調整する。
順伝播Forward Propagation
入力層から出力層へ向かって計算を進めること。
万能近似定理Universal Approximation Theorem
隠れ層が1層でもニューロン数を十分に増やせば、任意の連続関数を任意の精度で近似できるという定理。
ディープラーニングに必要な資源
大量の教師データ、高性能な計算資源(GPU/TPU)、長い学習時間が必要。データが少ない場合は転移学習やデータ拡張で補う。
バーニーおじさんのルール
モデルのパラメータ数の10倍のデータ量が必要とする経験則。
ディープラーニングのフレームワーク
TensorFlow(Google)、Keras、PyTorch(Meta)、Chainer(PFN)、Caffe、MXNet、JAXなど。scikit-learnは古典的機械学習用ライブラリ。
Define-and-Run / Define-by-Run
計算グラフを先に定義してから実行する方式(静的、TensorFlow 1系)と、実行しながら定義する方式(動的、Chainer/PyTorch)。

活性化関数

0/16
到達目標
  • 代表的な活性化関数の定義・使い分け・注意点を説明できる
  • ディープラーニングにおける活性化関数の役割を説明できる
活性化関数Activation Function
ニューロンの出力を決める非線形関数。これがないと何層重ねても線形変換にしかならず、表現力が上がらない。
シグモイド関数公式Sigmoid Function
出力を0〜1に写像するS字型関数。微分の最大値が0.25と小さいため、層を重ねると勾配消失問題を起こしやすい。二値分類の出力層で使われる。
tanh関数公式双曲線正接関数 / Hyperbolic Tangent
出力を−1〜1に写像する関数。微分の最大値は1でシグモイドより勾配消失しにくいが、依然として問題は残る。
ReLU関数公式Rectified Linear Unit / 正規化線形関数
入力が0以下なら0、0より大きければそのまま出力する関数。微分値が1のため勾配消失が起きにくく、計算も高速。現在の標準。ただし負の領域で勾配が0になる(dying ReLU)。
Leaky ReLU関数公式リーキーReLU
負の入力に対しても小さな傾き(例:0.01x)を持たせたReLUの改良。dying ReLU問題を緩和する。必ずしもReLUより性能が良いとは限らない。
ソフトマックス関数公式Softmax Function
出力の総和が1になるよう変換する関数。多クラス分類の出力層で各クラスの確率を表現するのに用いる。
勾配消失問題公式Vanishing Gradient Problem
誤差逆伝播の際、層を遡るほど勾配が小さくなり、入力層側の重みが更新されなくなる問題。シグモイド関数の微分の最大値が0.25であることが主因。ReLUやスキップ結合で緩和する。
Parametric ReLU (PReLU)パラメトリックReLU
Leaky ReLUの傾きを学習可能なパラメータにしたもの。
Randomized ReLU (RReLU)
負の領域の傾きをランダムに決めるReLUの変種。
ELUExponential Linear Unit
負の領域を指数関数で滑らかにしたReLUの改良版。
GELUGaussian Error Linear Unit
BERTやGPTなどTransformer系で標準的に使われる滑らかな活性化関数。
Swish
x·sigmoid(x)で定義される滑らかな活性化関数。ReLUを上回る性能を示すことがある。
Maxout
複数の線形関数の最大値を出力する活性化関数。
ステップ関数Step Function
閾値を境に0か1を出力する関数。形式ニューロンで用いられたが、微分できないため学習に使えない。
恒等関数Identity Function
入力をそのまま出力する関数。回帰問題の出力層で用いる。
ハードシグモイドHard Sigmoid
シグモイドを直線で近似した計算の軽い関数。

誤差関数

0/12
到達目標
  • 誤差関数の基礎的な知識を理解する
  • 代表的な誤差関数を理解する
  • 適用するタスクに応じて適切な誤差関数を選択できる
誤差関数損失関数 / Loss Function
モデルの予測と正解のズレを数値化する関数。これを最小化するようにパラメータを学習する。
平均二乗誤差公式MSE / Mean Squared Error
予測値と実測値の差の二乗の平均。回帰問題の標準的な誤差関数。
交差エントロピー公式Cross Entropy
2つの確率分布の隔たりを表す指標。分類問題の標準的な誤差関数。ソフトマックス関数と組み合わせて用いる。
カルバック・ライブラー情報量 (KL)公式KLダイバージェンス / Kullback-Leibler Divergence
2つの確率分布の差異を測る非負の量。分布が一致するとき0。非対称(P→QとQ→Pで値が異なる)なので厳密な距離ではない。VAEの正則化項などに用いる。
Contrastive Loss公式対照損失
2つの入力ペアが同じクラスなら特徴空間で近く、異なるクラスなら一定以上離れるように学習させる損失関数。距離学習・自己教師あり学習で用いる。
Triplet Loss公式トリプレット損失
基準(アンカー)・同クラス(ポジティブ)・異クラス(ネガティブ)の3つ組を用い、アンカーとポジティブの距離がネガティブより小さくなるように学習する損失関数。顔認証などに用いる。
バイナリ交差エントロピーBinary Cross Entropy
二値分類で用いる交差エントロピー。シグモイド関数と組み合わせる。
ヒンジ損失Hinge Loss
SVMで用いられる損失関数。マージンを侵した分だけ罰則を与える。
Huber損失フーバー損失
誤差が小さいときは二乗誤差、大きいときは絶対誤差のように振る舞う損失関数。外れ値に頑健。
JSダイバージェンスJensen-Shannon Divergence
KLダイバージェンスを対称化した指標。GANの目的関数と関係が深い。
尤度・最尤推定Likelihood / Maximum Likelihood Estimation
データの得られやすさ(尤度)を最大化するようパラメータを推定する考え方。交差エントロピーの最小化は最尤推定と等価。
距離学習Metric Learning
データ間の「意味的な近さ」を反映した距離(埋め込み空間)を学習する枠組み。Contrastive Loss、Triplet Lossを用いる。

正則化公式Regularization
モデルの複雑さにペナルティを課し、過学習を抑えて汎化性能を高める手法の総称。
L0正則化公式L0 Regularization
非ゼロのパラメータの「個数」にペナルティを課す正則化。組み合わせ最適化となり計算が困難なため、実用ではL1で近似する。
L1正則化公式L1 Regularization / ラッソ正則化
パラメータの絶対値の和にペナルティを課す。不要なパラメータが厳密に0になりやすく、スパースな(疎な)モデルとなり特徴選択の効果がある。
L2正則化公式L2 Regularization / リッジ正則化 / 荷重減衰
パラメータの二乗和にペナルティを課す。パラメータを全体的に小さく抑え、滑らかなモデルになる。0にはなりにくい。
ラッソ回帰公式Lasso Regression
L1正則化を加えた線形回帰。変数選択の効果がある。
リッジ回帰公式Ridge Regression
L2正則化を加えた線形回帰。多重共線性に強い。
ドロップアウト公式Dropout
学習時にランダムにノードを無効化する正則化手法。実質的に多数のネットワークのアンサンブル学習となる。推論時は全ノードを使う。ヒントンらが提案。
Elastic Netエラスティックネット
L1正則化とL2正則化を組み合わせた手法。
早期終了Early Stopping
検証データの誤差が悪化し始めた時点で学習を打ち切る手法。ジェフリー・ヒントンは「Beautiful FREE LUNCH」と呼んだ。
データ拡張Data Augmentation
データを水増しすることで実質的にデータ量を増やし、過学習を抑える。
ラベル平滑化Label Smoothing
正解ラベルを1.0ではなく0.9などに緩めることで、モデルの過信を防ぐ正則化手法。
スパース性Sparsity
多くのパラメータが0である状態。L1正則化により得られ、モデルの解釈性・軽量性が高まる。
正規化・標準化との違いNormalization / Standardization
正則化(regularization)は過学習抑制の手法。正規化は値の範囲を0〜1に揃えること、標準化は平均0・分散1に揃えること。混同注意。

誤差逆伝播法

0/8

  • 誤差逆伝播法の適用時に生じる問題とその主たる原因について説明できる
誤差逆伝播法バックプロパゲーション / Backpropagation
出力層で算出した誤差を、出力層側から入力層側へ逆向きに伝播させながら各重みの勾配を求め、パラメータを更新する学習アルゴリズム。1986年にラメルハート・ヒントンらが普及させた。
連鎖律公式Chain Rule / 合成関数の微分
合成関数の微分は各段の微分の積で表せるという法則。誤差逆伝播法の数学的な根幹。
勾配消失問題公式Vanishing Gradient Problem
層を遡るほど勾配が0に近づき、入力層側の重みが更新されなくなる問題。1未満の微分値が繰り返し掛け合わされることが原因。
勾配爆発問題公式Exploding Gradient Problem
勾配が指数的に大きくなり学習が発散する問題。特にRNNで起きやすい。勾配クリッピングで対処する。
信用割当問題公式Credit Assignment Problem
最終的な結果に対して、どの層のどのニューロンがどれだけ寄与したかを適切に割り当てる問題。誤差逆伝播法はこれを解く手法にあたる。
勾配クリッピングGradient Clipping
勾配の大きさに上限を設けて切り詰め、勾配爆発を防ぐ手法。
自動微分Automatic Differentiation
計算グラフをたどって微分を機械的に計算する仕組み。ディープラーニングフレームワークの中核機能。

最適化手法

0/32
到達目標
  • 勾配降下法の概要を理解する
  • 勾配降下法の問題とそれを解決するための手法を列挙できる
  • 勾配降下法の計算を効率化する方法を説明できる
  • ハイパーパラメータの概要と代表的な調整方法を列挙・説明できる
勾配降下法公式Gradient Descent / 最急降下法
誤差関数の値が小さくなる方向(勾配の逆方向)へパラメータを少しずつ更新し、最小値を探す最適化手法。
学習率公式Learning Rate
1回の更新でパラメータをどれだけ動かすかを決めるハイパーパラメータ。大きすぎると発散、小さすぎると収束が遅く局所最適解に陥りやすい。
局所最適解公式Local Minimum
誤差関数の一部分でのみ最小となる解。大域最適解ではないのに学習が止まってしまう原因。
大域最適解公式Global Minimum
誤差関数全体で真に最小となる解。本来到達したい解。
鞍点公式Saddle Point
ある方向から見ると極小、別の方向から見ると極大となる点。高次元では局所最適解より鞍点が学習停滞の主因とされる。
プラトーPlateau
鞍点付近などで勾配がほぼ0となり、学習が停滞する状態。
バッチ学習公式Batch Learning / 一括学習
全訓練データを使って1回の更新を行う方式。安定するが計算コストが高く、局所解に陥りやすい。
オンライン学習公式Online Learning / 逐次学習
データ1件ごとにパラメータを更新する方式。確率的勾配降下法(SGD)に相当。局所解を抜け出しやすいが更新が不安定。
ミニバッチ学習公式Mini-batch Learning
データを小さな塊(ミニバッチ)に分けて更新する方式。バッチ学習とオンライン学習の中間で、実務の標準。
確率的勾配降下法 (SGD)公式Stochastic Gradient Descent
データをランダムに選んで勾配を計算し更新する手法。ランダム性により局所最適解を脱出しやすい。
イテレーション公式Iteration
パラメータの更新回数。1エポックあたりのイテレーション数=データ数÷バッチサイズ。
エポック公式Epoch
訓練データ全体を何回学習に使ったかを表す単位。
バッチサイズBatch Size
1回の更新に用いるデータ数。
モーメンタム公式Momentum
過去の更新方向を慣性として加味し、振動を抑えて収束を速める手法。物理の慣性に着想を得ている。
AdaGrad公式アダグラッド
パラメータごとに学習率を自動調整する手法。更新が多いパラメータほど学習率を小さくする。学習が進むと学習率が小さくなりすぎる欠点がある。
RMSprop公式アールエムエスプロップ
AdaGradの「学習率が小さくなりすぎる」欠点を、過去の勾配を指数移動平均で忘れることで改善した手法。
AdaDelta公式アダデルタ
RMSpropと同様にAdaGradを改良した手法。学習率の設定を不要にした点が特徴。
Adam公式アダム
モーメンタムとRMSpropを組み合わせた手法。現在最も広く使われる最適化手法。
AdaBound公式
Adamの学習率に動的な上限・下限を設け、学習終盤はSGDのように振る舞わせる手法。
AMSBound公式
AMSGradにAdaBoundと同様の学習率のクリッピングを導入した手法。
AdamW
Adamの荷重減衰(weight decay)を正しく分離した改良版。Transformer系の学習で標準的。
Nesterov Accelerated GradientNAG / ネステロフの加速勾配法
モーメンタムの改良。先に慣性で進んだ位置で勾配を計算することで、より正確に更新する。
ハイパーパラメータ公式Hyperparameter
学習では決まらず、人間が事前に設定する値。学習率、バッチサイズ、層数、ユニット数など。
グリッドサーチ公式Grid Search
ハイパーパラメータの候補値をすべての組み合わせで総当たり探索する方法。
ランダムサーチ公式Random Search
ハイパーパラメータをランダムに選んで探索する方法。重要なパラメータが少ない場合、グリッドサーチより効率的。
早期終了公式Early Stopping
検証誤差が悪化し始めた時点で学習を打ち切る手法。過学習防止と計算時間短縮を両立する。
二重降下現象公式Double Descent
モデルの複雑さを上げていくと、テスト誤差が一度悪化した後に再び改善する現象。従来のバイアス・バリアンストレードオフでは説明できない。
ノーフリーランチの定理公式No Free Lunch Theorem
あらゆる問題に対して万能に優れたアルゴリズムは存在しないという定理。問題に応じた手法選択が必要であることを示す。
学習率スケジューリングLearning Rate Scheduling
学習の進行に応じて学習率を段階的に下げる手法。ステップ減衰、コサイン減衰、Warmupなど。
事前学習(積層オートエンコーダ)Pre-training
勾配消失問題への対策として、層ごとにオートエンコーダで教師なし学習し、後から全体を微調整した手法。ReLUやバッチ正規化の登場により現在ではあまり使われない。
重みの初期値Weight Initialization
Xavier(Glorot)初期化はシグモイド・tanh向け、He初期化はReLU向け。適切な初期化は勾配消失・爆発を防ぐ。
ベイズ最適化Bayesian Optimization
過去の試行結果をもとに、次に試すべきハイパーパラメータを効率よく決める手法。

RNNを時間方向に展開し、通常の誤差逆伝播法を適用する学習方法。系列が長いほど勾配消失・爆発が起きやすい。
勾配消失問題(RNN)公式Vanishing Gradient
時間方向に長く遡るほど勾配が消え、長期依存関係を学習できなくなる問題。LSTMのCEC(記憶セル)とゲート機構により大きく緩和された。
勾配爆発問題(RNN)公式Exploding Gradient
時間方向に勾配が指数的に増大して学習が発散する問題。勾配クリッピングで対処する。
Long Short Term Memory (LSTM)公式エルエスティーエム
CEC(誤差定数回転子)と3つのゲート(入力ゲート・出力ゲート・忘却ゲート)により長期依存関係を学習できるようにしたRNNの改良。1997年ホッフライター&シュミットフーバーが提案(原論文のゲートは入力・出力の2つで、忘却ゲートは1999年にゲルスらが追加)。
CECConstant Error Carousel / 誤差定数回転子
LSTMの記憶セル。勾配を減衰させずに保持することで長期記憶を可能にする中核部品。
ゲート機構公式Gate Mechanism
情報をどれだけ通すかをシグモイド関数で0〜1に制御する仕組み。LSTM・GRUの中核。
入力ゲートInput Gate
新しい情報をどれだけ記憶セルに書き込むかを制御するゲート。
出力ゲートOutput Gate
記憶セルの内容をどれだけ出力するかを制御するゲート。
忘却ゲートForget Gate
記憶セルの内容をどれだけ忘れるかを制御するゲート。1999年にゲルスらが追加した。
のぞき穴結合Peephole Connection
記憶セルの値をゲートの判断にも直接使えるようにしたLSTMの拡張。
Gated Recurrent Unit (GRU)公式ジーアールユー
LSTMを簡略化したモデル。リセットゲートと更新ゲートの2つのゲートのみを持ち、記憶セルを持たない。パラメータが少なく計算が速い。
エルマンネットワーク公式Elman Network
隠れ層の出力を次の時刻の隠れ層に戻す最も基本的なRNN。文脈層(コンテキストユニット)を持つ。
ジョルダンネットワーク公式Jordan Network
出力層の出力を次の時刻の隠れ層に戻すRNN。エルマンネットワークとの違いは、戻す元が隠れ層か出力層かの点。
双方向RNN (Bidirectional RNN)公式BiRNN
過去から未来へ進むRNNと未来から過去へ進むRNNを組み合わせ、前後両方の文脈を利用する。入力全体が事前に得られるタスク(文書分類など)で有効。リアルタイム予測には使えない。
教師強制公式Teacher Forcing
系列生成の学習時に、前ステップの予測値ではなく正解値を次の入力として与える手法。学習は安定・高速化するが、推論時との差異(露出バイアス)が生じる。
露出バイアスExposure Bias
教師強制で学習したモデルが、推論時に自分の誤った出力を入力とすることで誤差が蓄積する問題。
Seq2SeqSequence-to-Sequence
エンコーダで入力系列を固定長ベクトルに圧縮し、デコーダで出力系列を生成するモデル。機械翻訳・対話などに用いる。長文で情報が落ちる欠点をAttentionが解決した。

Attention

0/15
到達目標
  • Attentionの基礎的な知識を理解する
  • Attentionがどのような役割を果たすのか説明できる
  • RNNの問題点をAttentionはどのように解決できるか説明できる
  • Transformerについて理解する
Attention公式注意機構
入力のどの部分に注目すべきかを重み付けして選択的に情報を取り出す仕組み。Seq2Seqの「固定長ベクトルに全情報を詰め込む」ボトルネックを解消した。
Self-Attention公式自己注意機構
同じ系列内の要素どうしで注意を計算する仕組み。文中の任意の2単語の関係を距離に関係なく直接捉えられる。Transformerの中核。
Source Target Attention公式ソース・ターゲット注意機構
Query をデコーダ側から、Key と Value をエンコーダ側から取る Attention。Encoder-Decoder Attentionとも呼ばれる。
Multi-Head Attention公式マルチヘッド注意機構
Attentionを複数のヘッドに分けて並列に計算し、結果を結合する仕組み。異なる観点(構文的関係・意味的関係など)の関係性を同時に捉えられる。
クエリ公式Query / Q
「何を探しているか」を表すベクトル。Keyとの類似度を計算する側。
キー公式Key / K
「何を持っているか」を表すインデックス的なベクトル。Queryとの内積で関連度が測られる。
バリュー公式Value / V
実際に取り出される情報の中身のベクトル。Attention重みで加重和される。
Transformer公式トランスフォーマー
2017年Google「Attention Is All You Need」で提案。RNNや畳み込みを一切使わずSelf-Attentionのみで構成。並列計算が可能で長距離依存も捉えられ、BERT・GPTなど現代のLLMの基盤となった。
位置エンコーディング公式Positional Encoding
Transformerは系列の順序情報を持たないため、単語の位置情報をsin/cos関数などで埋め込みに加算する仕組み。
Seq2Seq公式Sequence-to-Sequence
エンコーダ・デコーダ構成で可変長の系列を別の系列に変換するモデル。機械翻訳・要約・対話に用いる。
Scaled Dot-Product Attentionスケール付き内積注意
QとKの内積を次元数の平方根で割ってからソフトマックスを取るAttention。次元が大きいときの勾配消失を防ぐためにスケーリングする。
エンコーダ・デコーダEncoder-Decoder
入力を内部表現に変換する部分と、そこから出力を生成する部分からなる構成。
Attentionによる解決点
RNNの逐次処理による並列化困難、長距離依存の学習困難、固定長ベクトルのボトルネックという3つの問題を同時に解決した。
Feed Forward Network (FFN)位置ごとの全結合層
Transformerブロック内でAttentionの後に置かれる2層の全結合層。各位置に独立に適用される。
Attentionの可視化
どの単語に注目したかを可視化でき、モデルの解釈性向上に役立つ。

オートエンコーダ

0/15
到達目標
  • オートエンコーダの概要を理解する
  • ディープラーニングにおけるオートエンコーダの役割を説明できる
  • オートエンコーダの代表的な亜種を理解する
オートエンコーダ自己符号化器 / Autoencoder
入力をそのまま出力として再現するよう学習する教師なしのニューラルネットワーク。中間層で低次元表現(潜在変数)を獲得する。入力層と出力層のノード数は同じ。
次元削減公式Dimensionality Reduction
オートエンコーダの中間層のノード数を入力より少なくすることで、情報を圧縮した低次元表現を得ること。
事前学習公式Pre-training
勾配消失問題への対策として、層ごとにオートエンコーダで教師なし学習してから全体を微調整する手法。ヒントンが2006年に提案。現在はReLUやバッチ正規化の登場によりあまり使われない。
積層オートエンコーダ公式Stacked Autoencoder
オートエンコーダを何層も積み重ねたもの。層ごとに順に学習(貪欲法的な事前学習)する。
変分オートエンコーダ (VAE)公式Variational Autoencoder
潜在変数を確率分布(平均と分散)として学習する生成モデル。潜在空間からサンプリングして新しいデータを生成できる。損失は再構成誤差+KLダイバージェンス。
VQ-VAE公式Vector Quantised-VAE
潜在表現を連続値ではなく離散的なコードブックのベクトルに量子化するVAE。posterior collapseを回避でき、高品質な画像・音声生成に用いられる。
info VAE公式インフォVAE
入力と潜在変数の相互情報量を最大化するようにVAEを改良したモデル。潜在変数が無視される問題を緩和する。
β-VAE公式ベータVAE
KLダイバージェンス項に係数βを掛けて重みを強めたVAE。潜在変数の各次元が独立した意味を持つ「もつれのほどけた(disentangled)」表現を獲得しやすい。
潜在変数Latent Variable
データの背後にあると仮定される、直接観測できない低次元の表現。
再構成誤差Reconstruction Error
入力と復元出力の差。オートエンコーダの主要な損失。異常検知にも利用される。
Reparameterization Trick再パラメータ化トリック
サンプリング操作を微分可能にするため、乱数を外部から与える形に書き換える技法。VAEの学習に不可欠。
デノイジングオートエンコーダDenoising Autoencoder
入力にノイズを加え、元のきれいな入力を復元させるオートエンコーダ。頑健な特徴を学習できる。
スパースオートエンコーダSparse Autoencoder
中間層の活性に対しスパース性の制約を課したオートエンコーダ。
制限付きボルツマンマシン (RBM)Restricted Boltzmann Machine
可視層と隠れ層の2層からなる確率的な生成モデル。ヒントンによる事前学習に用いられた。※シラバス2024でキーワードからは削除。
ディープビリーフネットワーク (DBN)Deep Belief Network
RBMを積み重ねた深層生成モデル。

データ拡張

0/16
到達目標
  • データ拡張の基礎的な知識を理解する
  • 代表的なデータ拡張手法について理解する
  • タスクやデータセットに応じて使用するデータ拡張手法を選択できる
データ拡張Data Augmentation
元のデータに変換を加えて疑似的にデータ量を増やす手法。過学習の抑制と汎化性能の向上が目的。タスクの意味を壊す変換(数字の6を180度回転させるなど)は避ける必要がある。
Crop公式クロップ / 切り抜き
画像の一部を切り出す拡張。ランダムクロップが一般的。
Random Flip公式ランダム反転
画像を左右(または上下)にランダムに反転させる拡張。文字認識など左右非対称が意味を持つタスクでは不適。
Rotate公式回転
画像を回転させる拡張。
Contrast公式コントラスト調整
画像の明暗の差を変化させる拡張。
Brightness公式明度調整
画像の明るさを変化させる拡張。照明条件の違いに頑健にする。
noising公式ノイズ付加
画像や信号にランダムノイズを加える拡張。頑健性を高める。
Cutout公式カットアウト
画像の一部の矩形領域を塗りつぶす(マスクする)拡張。部分的な隠れに強くなる。
Random Erasing公式ランダムイレージング
画像のランダムな領域をランダムな値で置き換える拡張。Cutoutに類似。
Mixup公式ミックスアップ
2枚の画像とそのラベルを一定比率で線形に混合して新しい学習データを作る拡張。
CutMix公式カットミックス
ある画像の一部を切り取って別の画像に貼り付け、ラベルも面積比で混合する拡張。MixupとCutoutの利点を併せ持つ。
RandAugment公式ランドオーグメント
複数の拡張手法から適用する数と強さの2つのパラメータだけでランダムに組み合わせる手法。探索コストが低い。
paraphrasing公式言い換え
自然言語処理におけるデータ拡張。文の意味を保ったまま言い換える(逆翻訳、同義語置換など)。
AutoAugmentオートオーグメント
強化学習でデータ拡張の方策自体を探索・自動設計する手法。
データ拡張の注意点
テストデータには適用しない(TTAを除く)。ラベルの意味が変わる変換は避ける。医療画像など不自然な変換が有害な領域では慎重に選ぶ。
転移学習との併用
データが少ない場合は、データ拡張と転移学習・ファインチューニングを組み合わせるのが定石。

画像認識

0/40
到達目標

  • 代表的な画像認識モデルについて理解する

一般物体認識公式Generic Object Recognition
画像に何が写っているかを一般的なカテゴリ(犬、車など)で認識するタスク。ILSVRCの中心課題。
物体識別公式Object Identification / 画像分類
画像全体に対して1つのクラスラベルを与えるタスク。特定物体認識(個体の識別)を指す場合もある。
物体検出公式Object Detection
画像中の物体の位置(バウンディングボックス)とクラスを同時に求めるタスク。
セマンティックセグメンテーション公式Semantic Segmentation
画像の全ピクセルにクラスラベルを割り当てるタスク。同じクラスの個体は区別しない。
インスタンスセグメンテーション公式Instance Segmentation
ピクセル単位のクラス分類に加え、同じクラスの個体どうしも区別するタスク。
パノプティックセグメンテーション公式Panoptic Segmentation
セマンティックセグメンテーション(背景などの不可算物=stuff)とインスタンスセグメンテーション(可算物=things)を統合したタスク。
姿勢推定公式Pose Estimation
人物の関節点(キーポイント)の位置を推定するタスク。
Open Pose公式オープンポーズ
複数人物の姿勢を同時にリアルタイム推定する手法。信頼度マップとPAFs(Parts Affinity Fields:部位間の関係を表すベクトル場)を用いる。
AlexNet公式アレックスネット
2012年ILSVRC優勝。8層のCNN。ReLU、ドロップアウト、データ拡張、GPU学習を採用し、第3次AIブームの契機となった。
VGG公式ブイジージー
2014年ILSVRC 2位。3×3の小さな畳み込みを重ねる単純な構成。VGG16、VGG19が有名。層を深くすることの有効性を示した。
GoogLeNet公式グーグルネット
2014年ILSVRC優勝。Inceptionモジュール(異なるサイズの畳み込みを並列に適用)と1×1畳み込みによる次元削減で、深さと計算効率を両立。
ResNet公式レズネット
2015年ILSVRC優勝。スキップ結合により152層という超深層を実現し、エラー率3.57%で人間の精度を超えた。
Wide ResNet公式ワイドレズネット
ResNetを深くする代わりにチャネル幅を広げたモデル。学習が速い。
DenseNet公式デンスネット
各層をそれ以降の全層と結合(concat)するネットワーク。特徴の再利用によりパラメータ効率が高い。
SENet公式Squeeze-and-Excitation Network
2017年ILSVRC優勝。チャネルごとの重要度を学習して重み付けする(Attention的な)機構を導入。
MobileNet公式モバイルネット
Depthwise Separable Convolutionにより軽量化したモデル。モバイル・組込み機器向け。
EfficientNet公式エフィシェントネット
深さ・幅・解像度を複合スケーリング係数でバランス良く拡大する設計。少ないパラメータで高精度を達成。
NAS (Neural Architecture Search)公式ニューラルアーキテクチャ探索
ネットワーク構造そのものを自動探索する技術。強化学習や進化的アルゴリズムを用いる。
MnasNet公式エムナスネット
NASにより、精度だけでなくモバイル端末での実行速度も目的関数に含めて探索したモデル。
Vision Transformer (ViT)公式ビジョントランスフォーマー
画像をパッチに分割して系列とみなし、Transformerで処理するモデル。大規模データで学習するとCNNを上回る。
R-CNNRegions with CNN features
物体検出の先駆け。Selective Searchで候補領域を約2000個抽出し、各領域をCNNで分類する2段階手法。処理が非常に遅い。
Fast R-CNN公式ファストR-CNN
画像全体を1度だけCNNに通し、特徴マップ上で候補領域を処理することで高速化した手法(RoIプーリング)。
Faster R-CNN公式ファスターR-CNN
候補領域の抽出自体をニューラルネットワーク(RPN: Region Proposal Network)で行い、end-to-endの学習を可能にした。
Mask R-CNN公式マスクR-CNN
Faster R-CNNにセグメンテーション用のマスク出力分岐を追加し、インスタンスセグメンテーションを実現した手法。
YOLO公式You Only Look Once
画像をグリッドに分割し、候補領域抽出と分類を1回のネットワーク処理で同時に行う1段階検出器。非常に高速でリアルタイム処理に適する。
SSD公式Single Shot MultiBox Detector
YOLOと同じ1段階検出器。複数解像度の特徴マップとデフォルトボックスを用い、様々な大きさの物体を検出する。
FPN (Feature Pyramid Network)公式特徴ピラミッドネットワーク
異なる解像度の特徴マップを組み合わせ、大小さまざまな物体の検出精度を高める構造。
FCN (Fully Convolutional Network)公式全層畳み込みネットワーク
全結合層を畳み込み層に置き換え、任意サイズの入力からピクセル単位の出力を得る。セマンティックセグメンテーションの基礎。
SegNet公式セグネット
エンコーダ・デコーダ構造のセグメンテーションモデル。プーリング時の位置情報(インデックス)を記憶してアップサンプリングに利用する。
U-Net公式ユーネット
エンコーダとデコーダをスキップ結合で繋いだU字型のセグメンテーションモデル。医療画像で広く使われ、拡散モデルのバックボーンにもなっている。
PSPNet公式Pyramid Scene Parsing Network
異なるスケールでプーリングした情報を統合(Pyramid Pooling Module)し、大域的な文脈を利用するセグメンテーションモデル。
DeepLab公式ディープラボ
Atrous(Dilated)畳み込みにより解像度を落とさずに受容野を広げるセグメンテーションモデル。ASPPモジュールを持つ。
バウンディングボックスBounding Box
物体を囲む矩形。物体検出の出力形式。
IoUIntersection over Union
予測領域と正解領域の重なり具合を表す指標。共通部分÷和集合。物体検出の評価やNMSに使う。
NMSNon-Maximum Suppression / 非最大抑制
重複した検出結果のうち、スコアが最大のもの以外を除去する後処理。
mAPmean Average Precision
物体検出の代表的な評価指標。クラスごとのAP(適合率-再現率曲線の下の面積)の平均。
Selective Search選択的検索
色や質感の類似性で領域を統合して物体候補を抽出する古典的手法。R-CNNで使用。
Swin Transformerスウィントランスフォーマー
ウィンドウを段階的にずらしながらAttentionを計算する階層的ViT。※シラバス2024でキーワードからは削除。
OCR光学文字認識 / Optical Character Recognition
画像中の文字を読み取る技術。※シラバス2024でキーワードからは削除。
画像キャプション生成Image Captioning
画像の内容を説明する文章を生成するタスク。CNN(エンコーダ)+RNN(デコーダ)が古典的構成。

文をまたいだ文章全体の構造や照応関係を解析する処理。
N-gram公式エヌグラム
連続するN個の単語(または文字)の並び。N=1でユニグラム、2でバイグラム、3でトライグラム。言語モデルや特徴量として使う。
BoW (Bag-of-Words)公式バッグ・オブ・ワーズ
文書を単語の出現回数のベクトルで表す手法。語順の情報は失われる。
ワンホットベクトル公式One-hot Vector
該当する要素だけ1、他は0のベクトル。語彙数分の次元が必要で高次元・疎になり、単語間の意味的な近さを表現できない(局所表現)。
TF-IDF公式Term Frequency - Inverse Document Frequency
単語の出現頻度(TF)と、その単語が少数の文書にしか現れないほど大きくなる希少性(IDF)の積。文書中の重要語を抽出する指標。
分散表現公式Distributed Representation / 埋め込み
単語を数百次元程度の密な実数ベクトルで表す方法。意味的に近い単語がベクトル空間で近くに配置される。
単語埋め込み公式Word Embedding
単語を低次元の密なベクトルに変換すること、またはそのベクトル。分散表現とほぼ同義。
word2vec公式ワードトゥベック
2013年トマス・ミコロフらが提案。「単語の意味は周囲の単語によって決まる」という分布仮説に基づき、単語の分散表現を学習する。「王−男+女≒女王」のようなベクトル演算が可能。
CBOW公式Continuous Bag-of-Words
word2vecの学習方式の一つ。周辺の単語から中心の単語を予測する。学習が高速。
スキップグラム公式Skip-gram
word2vecの学習方式の一つ。中心の単語から周辺の単語を予測する。低頻度語に強い。
fastText公式ファストテキスト
word2vecの発展形。単語を部分文字列(サブワード)の集合として扱うため、未知語や活用形に強い。Facebook開発。
ELMo公式Embeddings from Language Models
双方向LSTMを用い、文脈に応じて変化する単語ベクトル(文脈依存表現)を得るモデル。同じ単語でも文脈で表現が変わる。
BERT公式Bidirectional Encoder Representations from Transformers
2018年Google発表。Transformerのエンコーダを用い、双方向の文脈を捉える事前学習モデル。MLM(Masked Language Model:単語の穴埋め)とNSP(Next Sentence Prediction:次文予測)で事前学習し、各タスクにファインチューニングする。
GPT-n公式Generative Pre-trained Transformer
OpenAIによる自己回帰型(次の単語を予測)の言語モデル。Transformerのデコーダを用いる。GPT-3以降は巨大化により少数例だけで多様なタスクをこなせる(In-Context Learning)。
PaLM公式Pathways Language Model
Googleが開発した5400億パラメータの大規模言語モデル。
LLM (大規模言語モデル)公式Large Language Model
膨大なテキストで学習した超大規模な言語モデル。Transformerを基盤とし、多様なタスクを単一モデルで扱える。
ChatGPT公式チャットジーピーティー
2022年11月OpenAIが公開した対話型AIサービス。GPTにRLHF(人間のフィードバックによる強化学習)を適用し、指示に沿った自然な応答を実現。生成AIブームの起点。
Seq2Seq公式Sequence-to-Sequence
エンコーダ・デコーダにより系列を別の系列に変換するモデル。機械翻訳・要約・対話に用いる。
機械翻訳公式Machine Translation
ある言語の文を別の言語に翻訳するタスク。ルールベース→統計的(SMT)→ニューラル(NMT)と発展した。
統計的機械翻訳公式SMT / Statistical Machine Translation
大量の対訳コーパスから統計的に翻訳モデルと言語モデルを学習する方式。
感情分析公式Sentiment Analysis
文章から書き手の感情や評価の極性(ポジティブ/ネガティブ)を判定するタスク。
文書要約公式Text Summarization
文書の要点を短くまとめるタスク。原文から重要文を抜き出す抽出型と、新たに文を生成する生成型(抽象型)がある。
質問応答公式Question Answering
自然言語の質問に対して回答を返すタスク。ワトソンが代表例。
情報検索公式Information Retrieval
大量の文書から、クエリに関連する文書を探し出す技術。
GLUE公式General Language Understanding Evaluation
自然言語理解の複数タスクをまとめた標準ベンチマーク。より難しいSuperGLUEもある。
CEC公式Constant Error Carousel
LSTMの記憶セル。誤差を保持し勾配消失を防ぐ。※シラバスでは自然言語処理の項に掲載。
分布仮説Distributional Hypothesis
「単語の意味は、その単語が現れる文脈によって決まる」という仮説。分散表現の理論的根拠。
局所表現Local Representation
ワンホットベクトルのように、1つの概念を1つの次元で表す方法。分散表現の対義語。
コサイン類似度Cosine Similarity
2つのベクトルのなす角の余弦。単語や文書の意味的な近さを測る指標。−1〜1の値をとる。
サブワード分割Subword Tokenization
単語をさらに小さな単位に分割する方法。BPE、WordPiece、SentencePieceなど。未知語問題を緩和する。
BLEUブルー
機械翻訳の自動評価指標。生成文と参照訳のn-gramの一致度を測る。
ROUGEルージュ
文書要約の自動評価指標。参照要約との再現率ベースの一致度を測る。
Perplexityパープレキシティ / 困惑度
言語モデルの性能指標。次の単語の候補数の期待値に相当し、小さいほど良いモデル。
固有表現抽出 (NER)Named Entity Recognition
文中から人名・地名・組織名などの固有表現を抽出するタスク。
RoBERTa / ALBERT / DistilBERT / ELECTRA
BERTの派生モデル。学習方法の改善、パラメータ削減、蒸留による軽量化など。
T5 / BART
エンコーダ・デコーダ型のTransformer事前学習モデル。すべてのタスクをテキスト→テキストの変換として扱う(T5)。
SQuADStanford Question Answering Dataset
代表的な質問応答のベンチマークデータセット。

音声処理

0/25
到達目標

  • 音声処理タスクにおける特徴表現とその手法について理解する
  • 代表的な音声処理モデルについて理解する
音素公式Phoneme
言語において意味を区別する最小の音の単位。日本語では「あ/a/」「か/k/+/a/」など。
音韻公式Phonology / 音韻論
ある言語の話者が同じ音と認識する抽象的な音のまとまり。物理的な音(音声)と区別される概念。
A-D変換公式Analog to Digital Conversion
連続的なアナログ音声信号を離散的なデジタル信号に変換すること。標本化(サンプリング)→量子化→符号化の順に行う。
パルス符号変調器 (PCM)公式Pulse Code Modulation
A-D変換の代表的方式。標本化・量子化・符号化により音声をデジタル化する。
高速フーリエ変換 (FFT)公式Fast Fourier Transform
時間領域の信号を周波数領域(スペクトル)に高速に変換するアルゴリズム。音声の周波数成分を分析する基礎。
スペクトル包絡公式Spectral Envelope
周波数スペクトルの緩やかな外形。声道の共鳴特性を反映し、音韻の識別に重要な情報を含む。
フォルマント公式Formant
スペクトル包絡に現れる複数のピーク。声道の共鳴によって強調される周波数帯。
フォルマント周波数公式Formant Frequency
フォルマントのピークの周波数。低い方から第1フォルマント、第2フォルマント…と呼び、母音の識別に用いる。
メル尺度公式Mel Scale
人間の音の高さの知覚に合わせた周波数尺度。低周波は細かく、高周波は粗く扱う。
メル周波数ケプストラム係数 (MFCC)公式Mel-Frequency Cepstrum Coefficients
メル尺度に基づくスペクトル包絡の特徴量。音声認識の標準的な特徴量として長く使われてきた。
音声認識公式Speech Recognition / ASR
音声を文字列に変換するタスク。音響モデル・言語モデル・発音辞書の組み合わせが古典的構成。
隠れマルコフモデル (HMM)公式Hidden Markov Model
観測できない内部状態が確率的に遷移すると仮定する時系列モデル。ディープラーニング以前の音声認識の中核技術。
音声合成公式Speech Synthesis / TTS
テキストから音声を生成するタスク(Text-To-Speech)。
WaveNet公式ウェーブネット
2016年DeepMindが発表した音声波形を直接生成するモデル。Dilated Causal Convolutionにより高品質な音声合成を実現した。
CTC公式Connectionist Temporal Classification
入力(音声フレーム)と出力(文字列)の長さや対応位置が異なる場合に、アライメントを明示せず学習できる損失関数・手法。空白(ブランク)ラベルを導入する。音声認識や手書き文字認識に用いる。
話者識別公式Speaker Identification
音声から話者が誰であるかを特定するタスク。※話者照合(本人か否かの判定)とは区別される。
感情分析(音声)公式Emotion Recognition
音声の韻律や声質から話者の感情を推定するタスク。
標本化(サンプリング)Sampling
連続信号を一定間隔で値を取り出して離散化すること。サンプリング周波数が高いほど高音まで再現できる(標本化定理)。
量子化Quantization
標本化した値を有限段階の数値に丸めること。ビット数が大きいほど精度が高い。
音響モデルAcoustic Model
音の特徴と音素の対応関係を表すモデル。
言語モデル(音声認識)Language Model
単語の並びやすさを表すモデル。音響的に曖昧な認識結果を言語的な自然さで補正する。
発音辞書Pronunciation Dictionary
単語と音素列の対応を記した辞書。
スペクトログラムSpectrogram
時間・周波数・強度の3次元情報を可視化した図。短時間フーリエ変換(STFT)で得る。
Whisperウィスパー
OpenAIが公開した多言語音声認識モデル。大量の音声データで学習した汎用モデル。
音声区間検出 (VAD)Voice Activity Detection
音声が存在する区間を検出する処理。

深層強化学習

0/28
到達目標
  • 代表的な強化学習モデルについて理解する
  • 強化学習が実世界においてどのように活用されているか理解する
深層強化学習Deep Reinforcement Learning
強化学習の価値関数や方策をディープラーニングで近似する手法。高次元の状態(画像など)を直接扱える。
DQN公式Deep Q-Network
2013年DeepMind。CNNでQ関数を近似し、Atariのゲーム画面から直接プレイを学習。経験再生(Experience Replay)、ターゲットネットワーク、報酬クリッピングにより学習を安定化した。
ダブルDQN公式Double DQN
行動の選択と価値の評価を別のネットワークで行うことで、DQNのQ値の過大評価を抑える改良。
デュエリングネットワーク公式Dueling Network
Q値を状態価値V(s)とアドバンテージA(s,a)に分解して学習するDQNの改良。行動によらない状態の良さを効率的に学習できる。
ノイジーネットワーク公式Noisy Network
ネットワークの重みにノイズを加えることで、ε-greedyに代わる効率的な探索を実現する手法。
Rainbow公式レインボー
DQNの6つの改良(Double、Dueling、優先度付き経験再生、Noisy Net、多ステップ学習、カテゴリカルDQN)をすべて統合したモデル。
Agent57公式エージェント57
Atari 57ゲームすべてで人間のスコアを上回った初のエージェント。DeepMind。
A3C公式Asynchronous Advantage Actor-Critic
複数のエージェントを並列・非同期に動かして学習を高速化・安定化するActor-Critic手法。
APE-X公式エイプエックス
経験の収集を多数のアクターで並列化し、優先度付き経験再生を用いる分散強化学習手法。
PPO公式Proximal Policy Optimization
方策の更新幅を一定範囲に制限(クリップ)することで、安定かつ実装が容易な方策勾配法。RLHFでも標準的に使われる。
RLHF公式Reinforcement Learning from Human Feedback / 人間のフィードバックによる強化学習
人間の選好データから報酬モデルを学習し、それを報酬として言語モデルを強化学習で調整する手法。ChatGPTの有用性・安全性の中核技術。
sim2real公式シミュレーションから現実へ
シミュレータ上で学習した方策を現実世界のロボットに転移させること。現実とのギャップ(reality gap)が課題。
ドメインランダマイゼーション公式Domain Randomization
シミュレータの見た目や物理パラメータをランダムに変動させて学習し、現実環境への汎化性を高める手法。sim2realの代表的手法。
残差強化学習公式Residual Reinforcement Learning
従来の制御則をベースに、その差分(残差)のみを強化学習で獲得する手法。学習効率と安全性が向上する。
状態表現学習公式State Representation Learning
高次元の観測から、強化学習に有用な低次元の状態表現を学習すること。
オフライン強化学習公式Offline RL / バッチ強化学習
環境と新たに相互作用せず、事前に収集済みのデータのみで方策を学習する手法。実環境での試行が危険・高コストな領域で重要。
マルチエージェント公式Multi-Agent
複数のエージェントが同一環境で相互作用しながら学習する枠組み。協調・競争の両方がある。
連続値制御公式Continuous Control
行動が離散的な選択肢ではなく連続値(トルク、角度など)である制御問題。ロボット制御など。方策勾配法系の手法が適する。
OpenAI Five公式オープンAIファイブ
OpenAIが開発したDota 2をプレイするAI。2019年に世界王者チームに勝利。
アルファスター (AlphaStar)公式AlphaStar
DeepMindが開発したStarCraft IIをプレイするAI。2019年にグランドマスター級に到達。
報酬成形公式Reward Shaping
学習を促進するために報酬関数を設計・調整すること。設計を誤ると意図しない挙動(報酬ハッキング)を学習する。
経験再生Experience Replay
過去の経験をバッファに蓄積し、そこからランダムに取り出して学習することで、データ間の相関を減らし学習を安定化する手法。
ターゲットネットワークTarget Network
更新の目標値を計算するために一定期間固定するネットワーク。DQNの学習安定化に必須。
優先度付き経験再生Prioritized Experience Replay
TD誤差の大きい経験を優先的にサンプリングする改良。
AlphaFoldアルファフォールド
DeepMindのタンパク質立体構造予測AI。2024年ノーベル化学賞の対象となった。
AlphaZero / MuZero
AlphaZeroは囲碁・将棋・チェスを同一アルゴリズムで自己対戦のみから学習。MuZeroはルールすら与えられず環境モデル自体を学習する。
OpenAI Gym
強化学習アルゴリズムの開発・比較のための標準的な環境ライブラリ。
模倣学習・逆強化学習Imitation Learning / Inverse RL
専門家の行動データから方策を直接学習する手法/専門家の行動から報酬関数を推定する手法。

データ生成

0/23
到達目標
  • データ生成タスクの種類とその概要について理解する
  • 代表的なデータ生成モデルについて理解する
  • データ生成モデルが実世界においてどのように活用されているか理解する
生成モデルGenerative Model
データが生成される確率分布そのものを学習し、新しいデータを作り出せるモデル。識別モデル(クラス境界を学習)と対比される。
画像生成公式Image Generation
ノイズやテキストなどから新しい画像を生成するタスク。GAN、VAE、拡散モデルが代表的手法。
文章生成公式Text Generation
自然言語の文章を生成するタスク。自己回帰型の言語モデル(GPTなど)が用いられる。
音声生成公式Speech / Audio Generation
音声や音楽を生成するタスク。WaveNetなどが代表例。
敵対的生成ネットワーク (GAN)公式Generative Adversarial Network
2014年イアン・グッドフェローが提案。偽物を作る生成器(Generator)と本物か偽物かを見分ける識別器(Discriminator)を競わせて学習する。ヤン・ルカンが「機械学習において、この10年間で最も面白いアイデア」と評した。
生成器Generator
GANでノイズから偽データを生成するネットワーク。識別器を騙すように学習する。
識別器Discriminator
GANで入力が本物か生成物かを判定するネットワーク。正しく見分けるように学習する。
モード崩壊Mode Collapse
GANで生成器が限られた種類のデータしか生成しなくなる学習の失敗。多様性が失われる。
ミニマックスゲームMinimax Game
GANの学習は生成器と識別器の間の2人ゼロ和ゲームとして定式化される。理論的にはナッシュ均衡が最適解。
DCGAN公式Deep Convolutional GAN
GANに畳み込み層を導入し、学習を安定化させた基本的なモデル。プーリングを使わずストライド付き畳み込みを用いるなどの設計指針を示した。
Pix2Pix公式ピクストゥピクス
ペアになった画像どうしの変換を学習する条件付きGAN。線画→写真、白黒→カラーなど。学習に対応付いた画像ペアが必要。
CycleGAN公式サイクルガン
ペアになっていない2つの画像ドメイン間の変換を学習するGAN。変換して戻すと元に戻る制約(Cycle Consistency Loss)を課す。馬↔シマウマ、夏↔冬など。
Diffusion Model公式拡散モデル
データに徐々にノイズを加える順拡散過程と、ノイズから徐々にデータを復元する逆拡散過程を学習する生成モデル。GANより学習が安定し多様で高品質な生成が可能。Stable DiffusionやDALL·E 2の基盤。
NeRF公式Neural Radiance Fields
複数視点の2D画像群から3Dシーンの放射輝度場をニューラルネットワークで表現し、任意視点の画像を生成する技術。
StyleGANスタイルガン
スタイルを層ごとに制御することで非常に高品質かつ属性を制御可能な顔画像生成を実現したGAN。
SRGANSuper-Resolution GAN
GANを用いて低解像度画像を高解像度化する超解像モデル。
Conditional GAN (cGAN)条件付きGAN
クラスラベルなどの条件を与えて、生成する内容を制御できるようにしたGAN。
変分オートエンコーダ (VAE)Variational Autoencoder
潜在変数を確率分布として学習する生成モデル。生成画像はGANよりぼやけやすいが学習が安定。
Latent Diffusion / Stable Diffusion潜在拡散モデル
画素空間ではなく低次元の潜在空間で拡散過程を行うことで、計算量を大幅に削減した拡散モデル。Stable Diffusionが代表例。
DALL·Eダリ
OpenAIのテキストから画像を生成するモデル。DALL·E 2以降は拡散モデルを採用。
ディープフェイクDeepfake
ディープラーニングを用いて人物の顔や声を精巧に偽造した動画・音声。悪用が社会問題となっている。
3D Gaussian Splatting
多数の3次元ガウス分布でシーンを表現し、NeRFより高速に高品質な3D描画を行う手法。
正規化フローNormalizing Flow
可逆な変換の連続により単純な分布を複雑な分布へ写す生成モデル。尤度を厳密に計算できる。

転移学習Transfer Learning
あるタスクで学習した知識を別の関連タスクに転用する手法。事前学習済みモデルの重みは固定し、追加した出力層付近のみを学習する。データが少ない場合に特に有効。
ファインチューニングFine-tuning / 微調整
事前学習済みモデルの重みを初期値として、モデル全体(または広い範囲)を新しいタスクのデータで再学習する手法。転移学習より高精度になりやすいが、より多くのデータと計算資源を要する。
事前学習公式Pre-training
大規模データで汎用的な表現を先に学習しておくこと。その後に個別タスクへ適応させる。
事前学習済みモデル公式Pre-trained Model

ラベルなしデータから、データ自身の一部を隠すなどして疑似的な正解を自動生成し学習する方式。BERTのMLM、対照学習(SimCLR、MoCo)など。大規模事前学習の中核技術。
半教師あり学習公式Semi-Supervised Learning
少量のラベルありデータと大量のラベルなしデータを併用して学習する方式。疑似ラベル(Pseudo Labeling)などを用いる。
破壊的忘却公式Catastrophic Forgetting / 壊滅的忘却
新しいタスクを学習すると、以前学習したタスクの性能が急激に低下してしまう現象。継続学習(Continual Learning)の主要課題。
One-shot学習公式One-shot Learning
各クラスにつき1つの例だけで新しいクラスを学習・識別する枠組み。
Few-shot学習公式Few-shot Learning
ごく少数(数個程度)の例だけで新しいタスクを学習する枠組み。
Zero-shot学習Zero-shot Learning
そのタスクの例を1つも見ずに、事前知識だけでタスクを遂行する枠組み。CLIPやLLMが典型例。
ドメイン適応Domain Adaptation
訓練データと運用データの分布が異なる場合に、その差を埋める技術。転移学習の一形態。
継続学習Continual Learning / 生涯学習
タスクを次々に学習しても過去の知識を保持し続けることを目指す枠組み。
メタ学習Meta-Learning / 学習の学習
「学習の仕方」自体を学習する枠組み。少数データへの素早い適応を目指す。MAMLが代表的。
対照学習Contrastive Learning
同じデータの別の見え方どうしを近づけ、異なるデータを遠ざけるように表現を学習する自己教師あり手法。SimCLR、MoCo、BYOLなど。
マルチタスク学習Multi-Task Learning
複数のタスクを1つのモデルで同時に学習する手法。タスク間で表現を共有することで汎化性能が高まる。
能動学習Active Learning
モデルが「ラベルを付けてほしいデータ」を自ら選び、アノテーションコストを最小化する枠組み。
連合学習Federated Learning
データを各端末に置いたまま、モデルの更新情報だけを集約して学習する分散学習。プライバシー保護に有効。

モデルの解釈性

0/11
到達目標
  • モデルの解釈性が必要な背景について理解する
  • 解釈性が必要なユースケースについて理解する
  • 解釈性の向上に寄与する代表的な手法について理解する
説明可能AI (XAI)公式Explainable AI
AIの判断根拠を人間が理解できる形で提示する技術・研究分野。米国DARPAが2017年に大規模プロジェクトを開始した。
ブラックボックス問題Black Box Problem
ディープラーニングは高精度だが、なぜその判断に至ったかを人間が説明できないという問題。医療・金融・採用など、説明責任が求められる分野で導入の障壁となる。
CAM公式Class Activation Mapping
GAP(グローバルアベレージプーリング)を利用し、画像のどの領域が分類に寄与したかをヒートマップで可視化する手法。GAPを持つ構造にしか適用できない。
Grad-CAM公式Gradient-weighted Class Activation Mapping
勾配情報を用いて重要領域を可視化する手法。CAMと違い、ネットワーク構造を変更せずさまざまなCNNに適用できる。
LIME公式Local Interpretable Model-agnostic Explanations
予測したい1つのデータの近傍でモデルを単純な線形モデルで局所的に近似し、判断根拠を説明する手法。モデルの種類を問わない(model-agnostic)。
SHAP公式SHapley Additive exPlanations
協力ゲーム理論のシャープレイ値に基づき、各特徴量が予測にどれだけ寄与したかを公平に配分して説明する手法。局所説明と大域説明の両方に使える。
Permutation Importance公式並べ替え重要度
ある特徴量の値をランダムにシャッフルしたときの精度の低下量で、その特徴量の重要度を測る手法。モデルの種類を問わない。
解釈性が必要なユースケース
医療診断、与信・融資審査、採用選考、自動運転、司法判断など、判断が人の権利や生命に影響し説明責任が生じる領域。
大域的説明・局所的説明Global / Local Explanation
モデル全体の振る舞いを説明するもの(特徴量重要度など)と、個々の予測を説明するもの(LIME、Grad-CAM)の区別。
Attentionの可視化
Transformerがどのトークンに注目したかを可視化する解釈手法。ただし注意重み=根拠とは限らない点に注意。
解釈性と精度のトレードオフ
一般に、解釈しやすい単純なモデル(線形回帰・決定木)は精度が低く、高精度なモデル(ディープラーニング)は解釈しにくい傾向がある。

モデル圧縮公式Model Compression

蒸留公式Knowledge Distillation / 知識蒸留
大きく高精度な教師モデルの出力(ソフトターゲット)を、小さな生徒モデルに学習させることで、小型モデルの精度を高める手法。
プルーニング公式Pruning / 枝刈り
重要度の低い重みやニューロンを削除してモデルを疎にする手法。
量子化公式Quantization
重みや活性値を32bit浮動小数点から8bit整数などの低い精度で表現し、モデルサイズと計算量を削減する手法。
宝くじ仮説公式Lottery Ticket Hypothesis
大きなネットワークの中には、単独で学習しても元と同等の性能に到達できる小さな部分ネットワーク(当たりくじ)が存在するという仮説。プルーニングの理論的根拠の一つ。

スマートフォン・車載・IoT機器など計算資源やバッテリーが限られた環境での推論、リアルタイム性の要求、通信コストとプライバシーへの配慮。
クラウドAICloud AI
サーバ側で推論を行う方式。潤沢な計算資源を使えるが、通信遅延・通信コスト・データ送信に伴うプライバシーリスクがある。
MobileNet / SqueezeNet
軽量化を設計段階から組み込んだアーキテクチャ。
Pruning後の再学習
枝刈り後に再学習(fine-tuning)することで精度低下を回復させるのが一般的。

平均公式Mean / 平均値
すべての値の合計を個数で割った値。外れ値の影響を受けやすい。
中央値公式Median
データを大きさ順に並べたときの中央の値。外れ値の影響を受けにくい。
最頻値公式Mode
データの中で最も多く出現する値。
分散公式Variance
データの散らばりの大きさ。各値と平均の差の二乗の平均。
標準偏差公式Standard Deviation
分散の平方根。元のデータと同じ単位で散らばりを表す。
共分散公式Covariance
2つの変数がどの程度一緒に変動するかを表す量。単位に依存するため大きさの比較には向かない。
相関係数公式Correlation Coefficient
共分散を各標準偏差で割って−1〜1に標準化した指標。1に近いほど強い正の相関、−1に近いほど強い負の相関、0は無相関。あくまで線形の関係の強さを表す。
偏相関係数公式Partial Correlation Coefficient
第三の変数の影響を取り除いた上での、2変数間の相関係数。疑似相関の判別に用いる。
疑似相関公式Spurious Correlation
直接の因果関係がないのに、共通の要因(交絡因子)によって相関があるように見える現象。
度数分布公式Frequency Distribution
データを区間(階級)に分け、各区間に含まれるデータの個数を示したもの。ヒストグラムで可視化する。
外れ値公式Outlier
他の値から大きく離れた値。測定ミスの場合もあれば、重要な異常を示す場合もある。
移動平均公式Moving Average
時系列データで一定期間の平均を順にずらして計算したもの。短期的な変動を平滑化し傾向を見る。
確率変数公式Random Variable
試行の結果に応じて値が定まる変数。離散型と連続型がある。
確率分布公式Probability Distribution
確率変数がとる値とその確率の対応。
確率密度公式Probability Density
連続型確率変数における確率の密度。区間で積分した値がその区間の確率になる。
期待値公式Expected Value
確率変数が平均的にとる値。値×確率の総和(または積分)。
条件付き確率公式Conditional Probability
事象Bが起きたという条件のもとで事象Aが起きる確率 P(A|B)。ベイズの定理の基礎。
正規分布公式Normal Distribution / ガウス分布
平均を中心に左右対称の釣鐘型をした連続確率分布。自然現象や誤差の分布として広く現れる。平均±1σに約68%、±2σに約95%が含まれる。
ベルヌーイ分布公式Bernoulli Distribution
成功・失敗の2値をとる1回の試行の確率分布。
二項分布公式Binomial Distribution
成功確率pのベルヌーイ試行をn回繰り返したときの成功回数の分布。
ポアソン分布公式Poisson Distribution
単位時間あたりに稀な事象が起こる回数の分布。平均と分散が等しい(いずれもλ)。
最尤法公式Maximum Likelihood Estimation / 最尤推定
観測データが得られる確率(尤度)を最大にするようにパラメータを推定する方法。
最小二乗法公式Least Squares Method
残差の二乗和を最小にするようにパラメータを決める方法。線形回帰の基本。
帰無仮説公式Null Hypothesis / H0
「差がない」「効果がない」など、否定されることを目的に立てる仮説。
対立仮説公式Alternative Hypothesis / H1
帰無仮説が棄却されたときに採択される、主張したい仮説。
相互情報量公式Mutual Information
2つの確率変数が共有する情報量。一方を知ることで他方の不確実性がどれだけ減るかを表す。独立なら0。
コサイン類似度公式Cosine Similarity
2つのベクトルのなす角の余弦。ベクトルの向きの近さを測り、大きさ(長さ)には影響されない。−1〜1の値をとる。
ユークリッド距離公式Euclidean Distance
2点間の直線距離。最も基本的な距離尺度。
マハラノビス距離公式Mahalanobis Distance
データの分散・共分散を考慮した距離。相関のあるデータの散らばりを反映するため、異常検知に有効。
p値・有意水準p-value / Significance Level
帰無仮説が正しいと仮定したときに、観測されたデータ以上に極端な結果が得られる確率/棄却の基準(通常0.05)。
第一種の過誤・第二種の過誤Type I / Type II Error
本当は正しい帰無仮説を誤って棄却してしまう誤り(偽陽性)/誤った帰無仮説を棄却できない誤り(偽陰性)。
大数の法則Law of Large Numbers
試行回数を増やすほど標本平均が母平均に近づくという法則。
中心極限定理Central Limit Theorem
母集団の分布によらず、標本平均の分布は標本サイズが大きいと正規分布に近づくという定理。
ベイズの定理Bayes' Theorem
事前確率と尤度から事後確率を求める公式。P(A|B)=P(B|A)P(A)/P(B)。ナイーブベイズやベイズ最適化の基礎。
ベクトル・行列・テンソルVector / Matrix / Tensor
1次元・2次元・3次元以上の数値の配列。ニューラルネットワークの計算はテンソル演算で表される。
内積Inner Product / Dot Product
2つのベクトルの対応する成分の積の総和。類似度計算やニューロンの計算の基本。
行列積Matrix Product
行列どうしの積。全結合層の計算そのもの。GPUが得意とする演算。
固有値・固有ベクトルEigenvalue / Eigenvector
行列を掛けても向きが変わらないベクトルとその倍率。主成分分析の基礎。
微分・偏微分Differentiation / Partial Derivative
関数の変化率を求める操作。多変数関数で1つの変数についてのみ微分するのが偏微分。勾配降下法の基礎。
勾配Gradient
各変数についての偏微分を並べたベクトル。関数が最も急に増加する方向を指す。
連鎖律Chain Rule
合成関数の微分は各段の微分の積になるという法則。誤差逆伝播法の根幹。
エントロピーEntropy / 情報量
事象の不確実性の大きさ。確率が均等なほど大きく、偏るほど小さい。
KLダイバージェンスKullback-Leibler Divergence
2つの確率分布の隔たりを測る量。非負で、一致するとき0。非対称。
対数Logarithm
積を和に変換する関数。尤度計算では対数尤度にして扱いやすくする。
ラグランジュの未定乗数法Lagrange Multiplier
制約条件付きの最適化問題を解く手法。SVMの定式化に用いる。

個人情報保護法

0/21
到達目標

  • 個人情報等の定義に従い、基本的な事例についてあてはめができる

  • 匿名加工情報・仮名加工情報の制度趣旨や基本事項を理解している
  • GDPRが適用される場合の概要を理解している
個人情報公式Personal Information
生存する個人に関する情報で、氏名・生年月日等により特定の個人を識別できるもの(他の情報と容易に照合でき識別できるものを含む)、または個人識別符号を含むもの。死者の情報や法人情報は原則として含まない。
個人識別符号公式Personal Identification Code
それ単体で個人を識別できる符号。①身体的特徴を変換した符号(顔認証データ、指紋、虹彩、DNA、声紋、歩行の態様など)、②公的な番号(マイナンバー、旅券番号、運転免許証番号、基礎年金番号など)。
要配慮個人情報公式Sensitive Personal Information
人種、信条、社会的身分、病歴、犯罪の経歴、犯罪被害の事実など、不当な差別や偏見が生じないよう特に配慮を要する情報。取得には原則として本人の同意が必要で、オプトアウトによる第三者提供は認められない。
個人データ公式Personal Data
個人情報データベース等を構成する個人情報。安全管理措置や第三者提供の制限などの義務が課される。
保有個人データ公式Retained Personal Data
事業者が開示・訂正・利用停止等の権限を持つ個人データ。本人からの開示請求等に応じる義務がある。
利用目的公式Purpose of Use
個人情報を取り扱う目的。できる限り特定し、あらかじめ公表するか取得後速やかに本人へ通知する必要がある。原則として目的外利用は本人の同意なくできない。
第三者提供公式Provision to Third Parties
個人データを本人以外の第三者に渡すこと。原則として本人の事前同意が必要。オプトアウト、法令に基づく場合、委託・事業承継・共同利用の場合は例外となる。
委託公式Outsourcing
利用目的の達成に必要な範囲で個人データの取扱いを外部に委託すること。第三者提供にあたらないが、委託先に対する監督義務を負う。
匿名加工情報公式Anonymously Processed Information
特定の個人を識別できないように加工し、かつ元の個人情報を復元できないようにした情報。本人の同意なく第三者提供や目的外利用ができる。加工方法の情報の削除・安全管理と、作成・提供時の公表義務がある。
仮名加工情報公式Pseudonymously Processed Information
他の情報と照合しない限り特定の個人を識別できないように加工した情報。2022年施行の改正で新設。内部での分析利用を柔軟にする趣旨で、原則として第三者提供は禁止。利用目的の変更が可能で、漏えい報告や開示請求への対応義務が緩和される。
GDPR公式General Data Protection Regulation / EU一般データ保護規則
2018年施行のEUの個人データ保護規則。EU域内の個人データを扱えばEU域外の事業者にも適用される(域外適用)。違反時の制裁金は最大で全世界年間売上高の4%または2000万ユーロのいずれか高い方。
十分性認定Adequacy Decision
EUが域外の国・地域の個人データ保護水準を十分と認める決定。日本は2019年に相互の十分性認定を受け、EUからのデータ移転が容易になった。
データポータビリティ権Right to Data Portability
自分のデータを構造化された形式で受け取り、他のサービスへ移す権利。GDPRが定める。
忘れられる権利Right to be Forgotten / 消去権
自分に関する個人データの削除を求める権利。GDPRで明文化された。
プロファイリングに関する権利
GDPRでは、profilingを含む自動化された処理のみに基づく重要な決定に服さない権利が定められている。
個人関連情報
生存する個人に関する情報で、個人情報・仮名加工情報・匿名加工情報のいずれにも該当しないもの(Cookie、閲覧履歴等)。提供先で個人データとなることが想定される場合、本人同意の確認が必要。
オプトアウトOpt-out
本人の求めに応じて第三者提供を停止することを前提に、あらかじめ通知・届出をしたうえで同意なく第三者提供する仕組み。要配慮個人情報には利用できない。
個人情報保護委員会Personal Information Protection Commission
個人情報保護法を所管する独立性の高い行政機関。監督・指導・勧告・命令を行う。
越境移転Cross-border Transfer
外国にある第三者へ個人データを提供すること。原則として本人の同意が必要で、移転先の制度に関する情報提供が求められる。
漏えい等報告義務
一定の個人データの漏えい等が生じた場合、個人情報保護委員会への報告と本人への通知が義務(2022年施行の改正で法定化)。
CCPA / CPRACalifornia Consumer Privacy Act
米国カリフォルニア州の消費者プライバシー法。個人情報の販売の停止を求める権利などを定める。

著作権法

0/16
到達目標
  • AI生成物の著作権の成否について具体的事例であてはめができる
  • 著作権法違反となるコードやデータ等の利用方法を理解している
  • AI生成物に関する著作権の論点と確立された考え方を理解している
  • ライセンスの必要性及びライセンス契約を理解している
  • 著作権法30条の4について制度趣旨と概要を理解している
著作物公式Copyrighted Work
「思想又は感情を創作的に表現したものであつて、文芸、学術、美術又は音楽の範囲に属するもの」(著作権法2条1項1号)。単なる事実やデータそのもの、アイデアは著作物にあたらない。
創作性公式Creativity / Originality
著作物の要件の一つ。作者の個性が何らかの形で表れていれば足り、芸術的価値の高さは問わない。ありふれた表現や、表現の選択の幅がないものには創作性が認められない。
著作権公式Copyright
著作物を独占的に利用できる権利。複製権、公衆送信権、翻案権などの支分権からなる財産権(著作財産権)と、公表権・氏名表示権・同一性保持権からなる著作者人格権に大別される。人格権は譲渡できない。
著作権侵害公式Copyright Infringement
他人の著作物を無断で利用すること。成立には「依拠性」(その著作物に接して作ったこと)と「類似性」(表現上の本質的特徴が共通すること)の両方が必要。
AI生成物公式AI-Generated Work
AIが生成した成果物。人間の創作的寄与がない場合は著作物とならず著作権が発生しないと考えられている。利用者が創作的な指示や選択・加筆を行った場合には、その人の著作物と認められうる。
利用規約公式Terms of Service
サービス提供者が定める利用条件。AI生成物の権利帰属や商用利用の可否は、著作権法だけでなく各サービスの利用規約によって定まる点に注意。
著作権法30条の4情報解析のための利用
著作物に表現された思想・感情の享受を目的としない利用(情報解析=機械学習の学習用途など)は、原則として著作権者の許諾なく行える。ただし「著作権者の利益を不当に害することとなる場合」は除かれる(例:海賊版であると知りながらの利用、作風を模倣する目的での意図的な学習等が議論される)。
学習段階と生成・利用段階
AIと著作権は段階を分けて考える。学習(入力)段階は30条の4により広く許容されうるが、生成・利用段階では既存著作物との依拠性・類似性があれば通常どおり著作権侵害となりうる。
依拠性Reliance
既存の著作物に接して、それをもとに作成したこと。偶然の一致では侵害にならない。AIの学習データに含まれていた場合、依拠性が認められやすいと議論されている。
類似性Similarity
表現上の本質的な特徴が共通していること。アイデアが同じでも表現が異なれば侵害にならない(アイデア・表現二分論)。
著作者人格権Moral Rights
公表権・氏名表示権・同一性保持権。一身専属的で譲渡・相続できない。契約では「行使しない」と定めるのが一般的。
私的使用のための複製Private Use
個人的または家庭内など限られた範囲での複製は許される(著作権法30条)。
引用Quotation
公正な慣行に合致し、報道・批評・研究等の正当な範囲内であれば、出所を明示して引用できる(32条)。主従関係・明瞭区別性が要件。
ライセンスLicense
著作権者が利用を許諾すること。ソフトウェアではMIT、Apache 2.0、GPL(コピーレフト)、データセットではCC BY、CC BY-NCなど。条件(帰属表示、改変・商用可否、継承義務)の確認が必須。
保護期間Term of Protection
原則として著作者の死後70年(法人著作は公表後70年)。
肖像権・パブリシティ権
著作権法上の権利ではないが、人の容貌をみだりに撮影・公表されない権利(肖像権)と、著名人の顧客吸引力を経済的に利用する権利(パブリシティ権)。生成AIによる人物画像生成で問題となる。

特許法

0/12
到達目標
  • 特許権と著作権のすみ分け・異同についてAIの場面に即して基本を理解している
  • 職務発明について基本を理解している
  • 発明、新規性、進歩性について、その趣旨を理解している
  • 特許権と営業秘密との違いについて理解している
知的財産権公式Intellectual Property Rights
人間の知的創造活動の成果に与えられる権利の総称。著作権、特許権、実用新案権、意匠権、商標権、営業秘密など。
発明公式Invention
「自然法則を利用した技術的思想の創作のうち高度のもの」(特許法2条1項)。数学的な公式やアルゴリズムそのもの、人為的な取り決めは発明にあたらないが、ハードウェア資源と協働して具体的に実現されるソフトウェアは発明となりうる。
特許権公式Patent Right
発明を独占的に実施できる権利。出願・審査を経て登録されて初めて発生する(著作権は創作と同時に自動的に発生する点が異なる)。存続期間は出願日から20年。
新規性公式Novelty
出願前に公然と知られていないこと。学会発表や論文公開の後に出願すると新規性を失う(例外規定はあるが期限がある)。
進歩性公式Inventive Step
その分野の通常の知識を持つ者が容易に発明できたものではないこと。
発明者公式Inventor
発明をした自然人。AI自体は発明者になれないというのが日本を含む各国の基本的な立場(DABUS事件)。
職務発明公式Employee Invention
従業者が職務として行った発明。あらかじめ契約や勤務規則で定めれば、発明の権利を初めから使用者に帰属させることができる。その場合、従業者は「相当の利益」を受ける権利を持つ。
特許権と著作権の違い
特許権は「アイデア(技術的思想)」を保護し、審査・登録が必要で存続期間20年。著作権は「表現」を保護し、無方式で発生し死後70年。同じ成果物に両方が及ぶこともある。
特許権と営業秘密の違い
特許は公開と引き換えに独占権を得る(20年で誰でも使える)。営業秘密は公開せず秘密のまま保護するが、他社が独自に開発した場合は差し止められない。学習済みモデルやアルゴリズムをどちらで守るかは戦略的判断。
DABUS事件
AI「DABUS」を発明者として出願した事案。日本・米国・英国・欧州いずれも「発明者は自然人でなければならない」として認めなかった(南アフリカ等一部で認められた例外あり)。
産業上の利用可能性Industrial Applicability
特許要件の一つ。産業として実施できること。医療行為(人間の治療方法)などは対象外。
実用新案権・意匠権・商標権
物品の形状等の考案(実用新案)、デザイン(意匠)、商品・役務の識別標識(商標)を保護する権利。

不正競争防止法

0/8
到達目標

営業秘密公式Trade Secret
不正競争防止法で保護される秘密情報。①秘密管理性(秘密として管理されていること)、②有用性(事業活動に有用な技術上・営業上の情報であること)、③非公知性(公然と知られていないこと)の3要件をすべて満たす必要がある。
秘密管理性Secrecy Management
営業秘密の要件。アクセス制限、マル秘表示、就業規則での定めなど、従業員が秘密と認識できる管理がされていること。3要件のうち実務上最も争点になりやすい。
有用性Usefulness
営業秘密の要件。事業活動に客観的に有用であること。失敗した実験データ(ネガティブインフォメーション)も有用性が認められうる。
非公知性Non-public Nature
営業秘密の要件。保有者の管理下以外では一般に入手できないこと。
限定提供データ公式Limited Provision Data
2018年改正で創設。①限定提供性(特定の者に提供する)、②相当量蓄積性、③電磁的管理性を満たすデータ。ビッグデータの取引を保護する趣旨で、秘密管理されておらず営業秘密になり得ないデータも保護される。無償で広く公開されているオープンデータは対象外。
特許権との違い
不正競争防止法は登録不要で、秘密のまま保護される。ただし独占権ではなく、不正な取得・使用・開示行為を規制するにとどまり、他社が独自開発した場合は止められない。
営業秘密の侵害行為
不正取得、不正使用、不正開示など。刑事罰(営業秘密侵害罪)も定められている。
技術的制限手段の回避
コピーガード等の技術的制限手段を回避する装置・プログラムの提供も不正競争行為とされる。

AI開発委託契約

0/16
到達目標
  • AI開発の各フェーズの内容とそれらが置かれている趣旨を理解している
  • 各フェーズの内容と適切な契約関係を理解している
  • 知的財産の帰属と利用条件について理解している
  • 秘密保持契約(NDA)に関する基本的事項を理解している
AI・データの利用に関する契約ガイドライン公式
経済産業省が2018年に公表(2019年改訂)。AI編とデータ編からなり、AI開発を「アセスメント段階→PoC段階→開発段階→追加学習段階」の4段階に分けて段階的に進める「探索的段階型開発方式」を提唱する。
探索的段階型開発方式
AI開発は事前に成果を予測しにくいため、段階ごとに契約を締結し、次に進むかを都度判断する方式。いきなり一括請負契約を結ぶリスクを避ける。
アセスメント段階Assessment Phase
一定量のデータで学習済みモデルの生成可能性を検証する段階。秘密保持契約(NDA)を締結するのが一般的。
PoC段階Proof of Concept Phase
学習用データセットを用いて実際に試行し、実現可能性を検証する段階。導入検証契約(準委任型)が適する。
開発段階Development Phase
学習済みモデルを実際に生成する段階。ソフトウェア開発契約を締結する。
追加学習段階Additional Learning Phase
生成された学習済みモデルに追加の学習を行う段階。保守運用契約や追加学習に関する契約を結ぶ。
請負契約公式Contract for Work
仕事の完成を目的とする契約。成果物の完成義務を負い、契約不適合責任(旧・瑕疵担保責任)が生じる。性能が事前に保証できないAI開発とは本質的に相性が悪い。
準委任契約公式Quasi-mandate Contract
一定の事務処理(業務の遂行)を目的とする契約。成果の完成義務は負わず、善管注意義務を負う。AI開発、特にPoC段階に適するとされる。
精度保証公式Accuracy Guarantee
学習済みモデルの性能を契約上どこまで保証するか。AIの性能はデータに依存し事前に保証しにくいため、原則として保証しない、または一定条件下での目標値として定めるのが一般的。
NDA公式Non-Disclosure Agreement / 秘密保持契約
開示された秘密情報を目的外に使用せず第三者に開示しないことを定める契約。秘密情報の定義、目的、期間、返還・破棄の条項が重要。AI開発ではアセスメント段階で締結する。
PoC公式Proof of Concept / 概念実証
本格開発の前に実現可能性を検証する工程。ここで得られた知見や生成物の権利帰属も契約で定める必要がある。
保守契約公式Maintenance Contract
納品後のモデルの監視・再学習・不具合対応などを定める契約。運用フェーズで必須。
知的財産の帰属IP Ownership
学習用データセット、学習済みモデル、学習済みパラメータ、生成物(AIプロダクト)それぞれについて、誰に権利が帰属し誰がどう利用できるかを契約で明確に定める必要がある。「利用条件」を細かく定める方が実務的とされる。
契約不適合責任Nonconformity Liability
納品物が契約内容に適合しない場合の責任(旧・瑕疵担保責任)。追完請求、代金減額、損害賠償、解除。
再委託Subcontracting
開発を第三者にさらに委託すること。可否と責任の所在を契約で定める。個人データを含む場合は監督義務にも注意。
責任分配・免責条項
AIの出力によって損害が生じた場合の責任範囲や上限を定める条項。

SaaS公式Software as a Service
ソフトウェアをインターネット経由でサービスとして提供する形態。利用者は成果物の引き渡しを受けるのではなく、サービスを継続的に利用する。
データ利用権公式Data Usage Rights
利用者が入力したデータを、提供者がサービス改善やモデルの再学習に利用できるかを定める権利。生成AIサービスでは特に重要な論点で、利用規約で明示される。
利用規約公式Terms of Service
サービス提供者が定型的に定める利用条件。定型約款として民法の規律が及ぶ。不当条項は無効となりうる。
精度保証公式Accuracy Guarantee
SaaS型でもモデルの出力精度は保証しないのが一般的。SLA(サービス品質保証)では稼働率など可用性を定めることが多い。
SaaS型の特殊性
①成果物の引き渡しがなく継続的なサービス提供である、②提供者がモデルを随時更新するため出力が変化しうる、③利用者データが提供者側に蓄積される、④サービス終了時のデータ返還・移行が問題となる。
SLAService Level Agreement / サービス品質保証
稼働率、応答時間、サポート体制などのサービス水準と、未達時の対応(利用料の減額等)を定める合意。
サービス終了時の措置
データの返還・削除、モデルの継続利用の可否、移行支援などを契約で定めておく必要がある(ベンダーロックインの回避)。
入力データの取扱い
利用者が入力したプロンプトやファイルが学習に使われるか、保存期間、第三者提供の有無を確認する必要がある。営業秘密や個人情報の入力には特に注意。
準拠法・裁判管轄
海外のAIサービスを利用する場合、準拠法や紛争解決の場所が海外となることがあるため確認が必要。

AI倫理公式AI Ethics

AIガバナンス公式AI Governance
AIのリスクを管理し、便益を最大化するための組織的・社会的な統治の仕組み。方針策定、体制整備、リスク評価、モニタリング、改善のサイクルで構成される。

法律・条例など、法的拘束力があり違反に制裁が伴う規範。予見可能性が高く実効性があるが、制定に時間がかかり、技術の進歩に追いつきにくい。
ソフトロー公式Soft Law
ガイドライン、業界の自主規制、原則など、法的拘束力を持たない規範。技術の変化に柔軟・迅速に対応できるが、実効性の担保が弱い。AI分野では当初ソフトロー中心だったが、近年ハードロー化が進む。
リスクベースアプローチ公式Risk-based Approach

ユネスコAI倫理勧告

公平性

0/12
到達目標

  • 公平性に対処するための要検討事項・技術の基礎を理解している
アルゴリズムバイアス公式Algorithmic Bias
アルゴリズムの出力が特定の属性の集団に対して系統的に不利・不公平になること。学習データの偏り、設計者の前提、目的変数の選び方などが原因となる。
データの偏り公式Data Bias
学習データが現実の分布や望ましい分布を反映していない状態。過去の差別的な判断を含むデータで学習すると、AIが差別を再生産・増幅する。
サンプリングバイアス公式Sampling Bias
標本の抽出方法に偏りがあり、母集団を正しく代表していない状態。特定の属性のデータが極端に少ないと、その集団への精度が著しく低くなる。
センシティブ属性公式Sensitive Attribute / 保護属性
人種、性別、年齢、宗教、障害の有無など、差別につながりうる属性。これらを直接使わなくても不公平が生じうる点が問題の核心。
代理変数公式Proxy Variable
センシティブ属性と強く相関する別の変数(郵便番号が人種の、身長が性別の代理になるなど)。センシティブ属性を除いても、代理変数を通じて差別が再現されてしまう。
公平性の定義公式Fairness Definitions
公平性には複数の定義があり、同時に満たすことが数学的に不可能な場合がある(不可能性定理)。代表的な定義に、集団間で予測の陽性率を揃える「Demographic Parity(統計的パリティ)」、真陽性率・偽陽性率を揃える「Equalized Odds」、個々の類似した個人を同様に扱う「Individual Fairness」などがある。何を公平とするかは価値判断を伴う。

米国の再犯予測システムCOMPASが、黒人被告に対して再犯リスクを高く誤判定する傾向があると報道された事例。公平性の指標間の対立を象徴する事例として知られる。

過去の採用データで学習した結果、女性に不利な評価をする傾向が判明し、運用が取りやめられた事例。

公平性への対処

確証バイアスConfirmation Bias

Adversarial Attack (Adversarial Examples)公式敵対的攻撃・敵対的サンプル

学習データに悪意あるデータを混入させ、モデルの精度を落としたり、特定の入力にだけ誤動作するバックドアを仕込む攻撃。Web上のデータを収集して学習する場合にリスクが高い。

セキュリティ・バイ・デザイン公式Security by Design
システムの企画・設計段階からセキュリティを組み込む考え方。事後的な対策より効果的かつ低コスト。
安全性の論点
AIの誤動作が人の生命・身体・財産に与える影響。自動運転、医療診断、産業機械の制御などで特に重要。フェイルセーフ設計と人間による監督が求められる。

AIの安全性評価の基準づくりを担う機関。日本でも2024年に設置された。

モデルの規模がある閾値を超えると、小規模モデルでは見られなかった能力(多段階推論など)が急に現れる現象。
トークンToken
LLMが処理する文字列の最小単位。単語より細かいサブワードであることが多い。日本語は英語より1文字あたりのトークン消費が多い傾向がある。
トークナイザTokenizer
文章をトークン列に分割する仕組み。BPE(Byte Pair Encoding)、WordPiece、SentencePieceなど。
コンテキストウィンドウContext Window / 文脈長
モデルが一度に扱えるトークン数の上限。これを超える情報は参照できない。近年は数十万トークン級まで拡大している。
自己回帰言語モデルAutoregressive Language Model
直前までの文脈から次のトークンを確率的に予測して生成するモデル。GPT系が該当する。
事前学習と事後学習Pre-training / Post-training
大量のテキストで汎用的な言語能力を獲得する段階と、指示追従性や安全性を高める段階(指示チューニング、RLHF等)。
指示チューニングInstruction Tuning
「指示と理想的な応答」のペアで追加学習し、指示に従う能力を高める手法。教師ありファインチューニング(SFT)として行われる。
アライメントAlignment
モデルの振る舞いを人間の意図・価値観・安全性の要求に合わせること。
RLHF人間のフィードバックによる強化学習 / Reinforcement Learning from Human Feedback
人間の選好データから報酬モデルを学習し、それを報酬としてLLMを強化学習(PPOなど)で調整する手法。ChatGPTの中核技術。
報酬モデルReward Model
人間の選好を模倣し、応答の良し悪しをスコア化するモデル。RLHFで用いる。
DPODirect Preference Optimization
報酬モデルと強化学習を経由せず、選好データから直接方策を最適化する手法。RLHFより簡便で安定。
Constitutional AI憲法AI
人間のフィードバックの代わりに、あらかじめ定めた原則(憲法)に基づきAI自身が応答を批評・改善する学習手法。Anthropicが提唱。
MoEMixture of Experts / 混合エキスパート
複数の専門家サブネットワークのうち一部だけを入力ごとに選んで使う構造。総パラメータ数を増やしつつ推論時の計算量を抑えられる。
蒸留(LLM)Distillation
大規模モデルの出力を使って小規模モデルを学習させ、性能を維持しつつ軽量化する手法。ライセンス上の制約に注意が必要。
オープンウェイトモデルOpen-weight Model
モデルの重みが公開され、自前の環境で実行・改変できるモデル。Llama、Mistral、Gemmaなど。学習データやコードまで公開されるとは限らないため「オープンソース」とは区別される。
合成データSynthetic Data
AIが生成した学習用データ。データ不足を補えるが、生成物で学習し続けると品質が劣化する「モデル崩壊(Model Collapse)」が懸念される。
モデル崩壊Model Collapse
AI生成データで再学習を繰り返すことで、分布の裾が失われ多様性・品質が劣化していく現象。
推論時スケーリングInference-time Scaling / Test-time Compute
推論時により多くの計算(長い思考過程)を使うことで性能を高めるアプローチ。推論特化モデルの基盤となる考え方。
補2

LLMの利用技術

0/27
到達目標
  • プロンプト設計、外部知識の活用、効率的な適応手法など、生成AIを使いこなすための技術。
プロンプトPrompt
生成AIに与える指示文・入力文。出力の質を大きく左右する。
プロンプトエンジニアリングPrompt Engineering
目的の出力を得るためにプロンプトを工夫・設計する技術。役割の指定、出力形式の指定、例示、段階的な指示などの手法がある。
システムプロンプトSystem Prompt
モデルの役割や制約をあらかじめ設定する、利用者からは見えない指示文。
In-Context Learning文脈内学習
パラメータを更新せず、プロンプト内に与えた例示や指示だけでタスクを遂行する能力。GPT-3で顕著になった。
Zero-shot / One-shot / Few-shotプロンプティング
例を与えずに指示だけで解かせる/1例だけ与える/数例与えるプロンプトの与え方。
Chain-of-Thought (CoT)思考の連鎖
「順を追って考えてください」のように途中の推論過程を明示的に出力させることで、複雑な推論の精度を高める手法。
Zero-shot CoT
「Let's think step by step(ステップバイステップで考えよう)」という一文を加えるだけで推論性能が向上する現象。
Self-Consistency自己整合性
複数の推論経路を生成し、最も多く得られた答えを採用する手法。CoTの精度をさらに高める。
Tree of Thoughts (ToT)思考の木
複数の思考の道筋を木構造で探索・評価しながら解を導く手法。
ReActReasoning + Acting
推論(Reasoning)と外部ツールの実行(Acting)を交互に行わせる枠組み。AIエージェントの基本形。
ハルシネーションHallucination / 幻覚
事実に基づかない、もっともらしい誤情報を生成してしまう現象。LLMが確率的に尤もらしい単語列を生成する仕組みに起因し、完全には解消できない。ファクトチェックとRAGが主な対策。
RAG検索拡張生成 / Retrieval-Augmented Generation
質問に関連する文書を外部データベースから検索し、その内容をプロンプトに含めて回答を生成する手法。最新情報や社内文書に対応でき、ハルシネーションを抑制し出典を示せる。モデル自体の再学習が不要。
ベクトルデータベースVector Database
テキストを埋め込みベクトルとして保存し、意味的な近さで高速に検索できるデータベース。RAGの基盤。
埋め込みEmbedding
テキストや画像を意味を反映した数値ベクトルに変換したもの。類似検索・分類に用いる。
チャンク分割Chunking
長い文書を検索しやすい適度な長さに分割する処理。RAGの精度を左右する。
PEFTParameter-Efficient Fine-Tuning
モデル全体ではなく、ごく一部のパラメータのみを更新する効率的なファインチューニング手法の総称。
LoRALow-Rank Adaptation
元の重みを固定したまま、低ランクの小さな行列だけを追加学習する代表的なPEFT手法。計算資源とストレージを大幅に節約でき、複数の用途別アダプタを切り替えて使える。
QLoRA
モデルを量子化した上でLoRAを適用し、さらに省メモリで学習できるようにした手法。
Adapter / Prefix Tuning / P-Tuning
層の間に小さなモジュールを挿入する、あるいは学習可能な擬似トークンを入力に付加するPEFT手法。
温度パラメータTemperature
出力の確率分布の鋭さを調整するパラメータ。低いほど確定的で保守的、高いほど多様で創造的な出力になる。
Top-k / Top-p サンプリングTop-k / Nucleus(Top-p) Sampling
次のトークンの候補を確率上位k個に限る(Top-k)/累積確率がpに達するまでの候補に限る(Top-p)生成方法。Nucleus SamplingはTop-pのみを指す呼称。
ビームサーチBeam Search
複数の候補系列を保持しながら最も確からしい出力系列を探索する生成方法。
AIエージェントAI Agent
目標を与えると、自ら計画を立て、ツールを使い、結果を評価しながら多段階のタスクを遂行するシステム。
Function Calling / Tool Use関数呼び出し・ツール利用
LLMが外部のAPIや計算機、検索などのツールを呼び出す仕組み。苦手な計算や最新情報の取得を補う。
マルチモーダルLLMVision Language Model
画像や音声も入力として受け取れるLLM。図表の読解、画面操作などに応用される。
ファインチューニングとRAGの使い分け
知識・情報の鮮度や出典が重要ならRAG、出力の形式・文体・専門的な振る舞いを固定したいならファインチューニング。両者は併用できる。
GitHub Copilot
LLMを用いたコード補完・生成サービス。ソフトウェア開発における生成AIの代表的な実用例。
